Projeto Lista de Tarefas

A Ana vive esquecendo coisas: comprar pão, pagar a conta de luz, levar o Rex ao veterinário. Neste projeto, ela ganha um programa de tarefas no terminal, com um menu: adicionar, ver, concluir, remover e sair. É o primeiro projeto do guia que guarda dados: primeiro numa lista, enquanto o programa está aberto, e no fim num arquivo, para as tarefas continuarem lá amanhã.

Você vai praticar
  • Um menu que se repete, com while True e match e case.
  • Listas: append(), pop(), índices e o índice -1.
  • Numerar os itens com enumerate().
  • Guardar cada tarefa num dicionário ({"titulo": …, "feita": …}) e mudar um valor dele (alterando chaves).
  • Validar o número escolhido com isdigit() e uma função que devolve a posição ou None.
  • Escrever e ler um arquivo de texto, e tratar o FileNotFoundError com try e except.

Versão 1 · O menu e a lista

Todo programa de menu tem o mesmo esqueleto: um laço que mostra as opções, lê a escolha e faz o que foi pedido, até a pessoa escolher sair. As tarefas ficam numa lista de textos.

            print("Até mais!")
            break
        case _:
            print("Opção inválida.")

Versão 2 · Concluir e remover

Uma tarefa agora tem duas informações: o título e se já foi feita. Um texto só não basta; cada tarefa vira um dicionário com duas chaves, e a lista passa a ser uma lista de dicionários:

tarefas = [
    {"titulo": "Pagar a conta de luz", "feita": True},
    {"titulo": "Levar o Rex ao veterinário", "feita": False},
]

{"titulo": titulo, "feita": False}A tarefa nova: o título digitado e "feita" valendo False (ainda não foi feita).
marca = "x" if tarefa["feita"] else " "Um if em uma linha: "x" para as feitas, espaço para as outras. Vira [x] ou [ ].
f"{numero}. [{marca}] {tarefa['titulo']}"Dentro da f-string, a chave vai com aspas simples ('titulo'), porque a f-string já usa as duplas. (Desde o Python 3.12 dá para repetir as aspas duplas lá dentro, mas aspas diferentes funcionam em qualquer versão e são mais fáceis de ler.)

Versão 3 · Funções e número validado

O match estava ficando enorme. Na versão 3, cada pedaço com nome próprio vira uma função: mostrar_menu, listar e, a mais importante, escolher_tarefa, que pergunta o número e só devolve uma posição se ela existir. Concluir e remover usam a mesma função, então a validação é escrita uma vez só. E o título vazio (só Enter) passa a ser recusado.

def mostrar_menu():
    print()
    print("1 - Adicionar tarefa")
    print("2 - Ver tarefas")
    print("3 - Concluir tarefa")
    print("4 - Remover tarefa")
    print("0 - Sair")


def listar(tarefas):
    """Mostra as tarefas numeradas a partir de 1, com [x] nas feitas."""
    if not tarefas:
        print("Nenhuma tarefa ainda.")
    for numero, tarefa in enumerate(tarefas, start=1):
        marca = "x" if tarefa["feita"] else " "
        print(f"{numero}. [{marca}] {tarefa['titulo']}")


def escolher_tarefa(tarefas):
    """Pergunta o número de uma tarefa e devolve a posição dela na lista (ou None)."""
    if not tarefas:
        print("Nenhuma tarefa ainda.")
        return None
    texto = input("Número da tarefa: ").strip()
    if not texto.isdigit():
        print(f'"{texto}" não é um número.')
        return None
    numero = int(texto)
    if not 1 <= numero <= len(tarefas):
        print(f"Não existe a tarefa {numero}. Escolha de 1 a {len(tarefas)}.")
        return None
    return numero - 1

print("=== Lista de Tarefas da Ana ===")

    mostrar_menu()

PeçaO que faz
open(ARQUIVO, "w", encoding="utf-8")Abre para escrever ("w", de write). Atenção: o "w" apaga o que havia no arquivo e começa do zero. Aqui é o que queremos: a cada salvar, o arquivo recebe a lista inteira, atualizada (veja Escrevendo Arquivos).
arquivo.write(f"[{marca}] …\n")Escreve uma linha. O write não pula linha sozinho, como o print: o \n no fim é obrigatório.
with open(ARQUIVO, encoding="utf-8") as arquivo:Sem o "w", abre para ler (o padrão). O with fecha o arquivo no fim do bloco.
linha.rstrip("\n")Tira só o \n do fim da linha (o r é de right, "direita"). Um strip() comum também tiraria espaços que façam parte do título.
linha.startswith("[x] ")"Começa com?": decide se a tarefa estava feita.
linha[4:]Uma fatia: tudo a partir da posição 4, ou seja, o texto depois de [x] (quatro caracteres: colchete, x, colchete, espaço).
except FileNotFoundError: passNa primeira vez, o arquivo ainda não existe, e o open daria FileNotFoundError. Aqui isso não é um problema: começa com a lista vazia. O pass ("passar") é a instrução que não faz nada.

As duas sessões do começo da página são desta versão: na primeira, o programa diz 0 tarefa(s) carregada(s) (o arquivo ainda não existia) e, ao sair, o tarefas.txt já tem as três tarefas; na segunda, ele carrega as três, e a remoção também vai para o arquivo.

Por que salvar depois de cada mudança, e não só ao sair?

Se o programa fosse interrompido no meio (um Ctrl+C, um erro, a bateria do notebook), tudo o que a Ana fez desde que abriu o programa se perderia. Salvando a cada mudança, o arquivo está sempre em dia. Com poucas tarefas, regravar o arquivo inteiro é instantâneo.

Formas diferentes de fazer

Validar o número: isdigit() ou try/except

A versão 3 testou o texto antes de converter. A Calculadora fez o contrário: tentou converter e tratou o erro. As duas funcionam aqui:

try:
    numero = int(texto)
except ValueError:
    print(f'"{texto}" não é um número.')
    return None
FormaQuando usar
texto.isdigit() antes do int()Números inteiros sem sinal, como o número de uma tarefa. Fácil de ler: "se não for só algarismos…".
try: int(texto) / except ValueErrorQuando o número pode ter sinal ou casas decimais ("-3", "2.5" com float). É o jeito mais comum em Python: "tente, e trate se der errado".

Resumo

  • Um programa de menu é um while True que mostra as opções, lê a escolha (como texto) e usa match; o break só no "sair".
  • A lista fica fora do laço. append acrescenta, pop(posição) remove e devolve.
  • A tela conta a partir de 1, a lista a partir de 0: enumerate(…, start=1) para mostrar, numero - 1 para achar.
  • O índice -1 é válido (o último item): um 0 digitado vira -1 e erra calado. Valide com 1 <= numero <= len(lista).
  • Um item com várias informações vira um dicionário; mudar a chave muda o item que está na lista.
  • Para os dados sobreviverem, grave num arquivo: "w" regrava tudo, "a" acrescenta no fim. Leia com try e trate o FileNotFoundError da primeira vez.
