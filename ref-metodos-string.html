Python Métodos de String

Esta é a página de consulta rápida dos métodos de string: as funções que todo texto (str) já traz e que você chama com um ponto, como em nome.upper(). O Python 3.14 tem 47 deles, para trocar maiúsculas e minúsculas, procurar, trocar, limpar, dividir, juntar, alinhar, testar e codificar textos. Cada linha traz um exemplo curto e o resultado real. A explicação passo a passo dos mais usados, com exercícios, está na aula Métodos de Texto.

Como ler as tabelas
  • Exemplo é o que você digitaria depois do >>> do modo interativo; Resultado é o que o Python 3.14.4 respondeu no computador da Ana. O modo interativo mostra textos entre aspas ('Ana'); com print() elas não aparecem.
  • Quando o exemplo dá erro, o resultado mostra a última linha da mensagem do Python (em inglês).
  • Espaços que importam estão marcados no texto da explicação. \n é a quebra de linha e \t é a tabulação (veja Caracteres de Escape).
  • A anatomia de uma chamada: "banana".count("a") = o texto, um ponto, o nome do método e, entre parênteses, os argumentos.
O texto original nunca muda

Strings são imutáveis: nenhum método altera o texto. Cada um devolve um texto novo, e quem quiser guardá-lo precisa de uma atribuição (nome = nome.capitalize()). Veja no terminal:

$ python3 -q
>>> nome = "ana"
>>> nome.upper()
'ANA'
>>> nome
'ana'
>>> nome[0] = "A"
Traceback (most recent call last):
  File "<python-input-3>", line 1, in <module>
    nome[0] = "A"
    ~~~~^^^
TypeError: 'str' object does not support item assignment
>>> nome = nome.capitalize()
>>> nome
'Ana'
>>> exit()

O nome.upper() mostrou 'ANA', mas nome continuou 'ana'. Trocar uma letra direto também não dá: TypeError: 'str' object does not support item assignment = "o objeto str não aceita atribuição a um item". O jeito certo é a última linha: guardar o texto novo na variável.

Pule direto para o grupo que você procura:

  • Maiúsculas e minúsculas: upper, lower, capitalize, title, swapcase, casefold
  • Procurar e contar: find, rfind, index, rindex, count, startswith, endswith
  • Trocar e limpar: replace, strip, lstrip, rstrip, removeprefix, removesuffix, expandtabs, maketrans, translate
  • Dividir e juntar: split, rsplit, splitlines, partition, rpartition, join
  • Alinhar e completar: center, ljust, rjust, zfill
  • Testar (os is…): isalpha, isdigit, isdecimal, isnumeric, isalnum, isspace, islower, isupper, istitle, isascii, isidentifier, isprintable
  • Formatar e codificar: format, format_map, encode
  • Operadores e funções que também servem para texto

find ou index?

Use in quando só quer saber se tem. Use find quando quer a posição e "não achou" é normal (teste se deu -1). Use index quando o texto tem que estar lá: se não estiver, o erro avisa logo. O -1 do find é traiçoeiro: texto[texto.find("x")] pega a última letra sem reclamar.

Experimente

Missão: o nome chegou do formulário com espaços sobrando e maiúsculas misturadas. Use strip() e title() (um depois do outro, na mesma linha) para que a saída fique [Ana Beatriz De Sousa]. Os colchetes mostram se ainda sobrou algum espaço.

entrada = "  ana BEATRIZ de sousa  "
nome = entrada
print(f"[{nome}]")

entrada = "  ana BEATRIZ de sousa  "
nome = entrada.strip().title()
print(f"[{nome}]")

Repare na solução: entrada.strip() devolve um texto novo, e o .title() é chamado nesse texto novo. Encadear métodos assim é muito comum.

Livre: teste qualquer método desta página com a frase, ou troque a frase.

frase = "O rato roeu a roupa do rei de Roma"
print(frase.lower().count("r"))
print(frase.split())
print(" ".join(reversed(frase.split())))
print(frase.replace("rato", "gato"))
print(frase.startswith("O"), frase.endswith("Roma"))
print(frase.upper().center(40, "*"))

Resumo

  • Os métodos de string nunca mudam o texto: devolvem um texto novo. Guarde-o com nome = nome.metodo().
  • Caixa: upper, lower, capitalize, title, swapcase; para comparar, casefold.
  • Procurar: find (dá -1), index (dá erro), count, startswith, endswith, e o operador in.
  • Limpar e trocar: strip e companhia (tiram letras das pontas), removeprefix/removesuffix (tiram um texto exato), replace, translate.
  • Dividir e juntar: split devolve uma lista; sep.join(lista) faz o contrário, e só com textos.
  • Alinhar: center, ljust, rjust, zfill. Testar: os is…, que dão False para "" (menos isascii e isprintable).
