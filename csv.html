Python CSV

A professora da escola do bairro mandou para a Ana as notas da turma numa planilha. A lojinha exporta o estoque do sistema de vendas. O banco deixa baixar o extrato. Os três chegam no mesmo formato: um arquivo CSV, a maneira mais simples e mais comum de guardar uma tabela num arquivo de texto. Nesta aula você aprende a ler e gravar esses arquivos com o módulo csv do Python, inclusive os que saem do Excel em português, que têm um jeitinho próprio.

Você vai aprender
  • O que tem dentro de um arquivo CSV.
  • A ler as linhas como listas com csv.reader e pular o cabeçalho com next().
  • Que tudo o que vem do CSV é texto, e como converter para número.
  • A gravar com csv.writer, writerow e writerows.
  • Por que sempre abrir com newline="".
  • A ler cada linha como um dicionário com DictReader e gravar com DictWriter.
  • O CSV do Excel brasileiro: ponto e vírgula (delimiter=";"), vírgula decimal e o utf-8-sig.
  • Os erros reais: KeyError, ValueError, arquivo fechado, leitor que "secou".

A ideia: uma tabela escrita em texto

Pense na tabela de notas no caderno da professora: cada linha é um aluno, cada coluna é uma informação (nome, turma, nota), e a primeira linha diz o nome de cada coluna. Para guardar isso num arquivo de texto simples, basta uma regra: uma linha da tabela por linha do arquivo, e uma vírgula entre uma coluna e outra. É isso que quer dizer CSV: Comma-Separated Values, "valores separados por vírgula".

nometurmanota
BiaA8.5
CaioB6.0
DudaA9.5
EnzoB7.0

A mesma tabela, como arquivo notas.csv, vista com o cat do terminal:

$ cat notas.csv
nome,turma,nota
Bia,A,8.5
Caio,B,6.0
Duda,A,9.5
Enzo,B,7.0

É só texto: dá para abrir no editor de textos, no Excel, no LibreOffice Calc ou no Google Planilhas. A primeira linha é o cabeçalho (os nomes das colunas); as outras são os dados.

Você poderia ler esse arquivo com o que já sabe (open, um for e split(",")). Mas o CSV tem casos chatos, como um nome que tem vírgula dentro, e o módulo csv, que já vem com o Python, resolve todos eles. A seção Formas diferentes mostra o split quebrando.

Cria um leitor (reader) de CSV em cima do arquivo aberto.
for linha in leitor:
A cada volta, o leitor entrega uma linha do arquivo já separada: uma lista com uma posição para cada coluna.

O cabeçalho veio junto, como se fosse um aluno chamado "nome". Quase sempre você quer separá-lo dos dados. O jeito é pedir a primeira linha ao leitor com next() ("próximo") antes do for:

import csv

with open("notas.csv", newline="", encoding="utf-8") as arquivo:
    leitor = csv.reader(arquivo)
    cabecalho = next(leitor)
    print("Colunas:", cabecalho)
    soma = 0
    quantos = 0
    for nome, turma, nota in leitor:
        print(f"{nome} (turma {turma}): {nota}")
        soma = soma + float(nota)
        quantos = quantos + 1

print(f"Média da turma: {soma / quantos:.2f}")

2. Gravando: csv.writer

O caminho de volta: você tem os dados numa lista de listas e quer um .csv para abrir na planilha.

import csv

produtos = [
    ["produto", "preco", "estoque"],
    ["café", "18.90", "12"],
    ["pão de queijo", "2.50", "40"],
    ["açúcar", "5.99", "0"],
]

with open("estoque.csv", "w", newline="", encoding="utf-8") as arquivo:
    escritor = csv.writer(arquivo)
    escritor.writerow(produtos[0])
    escritor.writerows(produtos[1:])

print("Gravei estoque.csv")

Abre para escrita ("w": cria o arquivo ou apaga o que havia). Mais uma vez, newline="".
csv.writer(arquivo)
Cria um escritor (writer) de CSV.
escritor.writerow(lista)
"Escreva uma linha" (write row): junta os itens com vírgulas e acrescenta a quebra de linha.
escritor.writerows(lista_de_listas)
"Escreva as linhas": o mesmo, para várias linhas de uma vez.

Os itens não precisam ser textos: writerow(["café", 18.9, 12]) também funciona, e o escritor transforma cada um em texto (o 18.9 sai como 18.9, sem o zero do fim; se a aparência importar, formate antes: f"{preco:.2f}").

As aspas que aparecem sozinhas

E se um valor tiver uma vírgula dentro? Um cliente cadastrado como "Silva, Ana" quebraria a regra "vírgula separa colunas". O escritor resolve: põe o valor entre aspas duplas. Se o valor tiver aspas, ele as dobra.

import csv

clientes = [
    ["nome", "cidade"],
    ["Silva, Ana", "Teresina"],
    ['Bia "Baixinha" Costa', "Recife"],
]

with open("clientes.csv", "w", newline="", encoding="utf-8") as arquivo:
    csv.writer(arquivo).writerows(clientes)

with open("clientes.csv", newline="", encoding="utf-8") as arquivo:
    for linha in csv.reader(arquivo):
        print(linha)

3. Cada linha como dicionário: DictReader

Com o reader, você lembra que a nota é a posição [2]. Se um dia a professora acrescentar uma coluna no meio, o programa passa a ler a coluna errada. O csv.DictReader usa o cabeçalho para dar nome a cada valor: cada linha vira um dicionário.

import csv

with open("notas.csv", newline="", encoding="utf-8") as arquivo:
    for aluno in csv.DictReader(arquivo):
        print(aluno)
        print("  ->", aluno["nome"], "tirou", aluno["nota"])

{'nome': 'Duda', 'turma': 'A', 'nota': '9.5'}

{'nome': 'Enzo', 'turma': 'B', 'nota': '7.0'}

csv.DictReader(arquivo)
Um leitor que usa a primeira linha como as chaves. Não precisa de next(): o cabeçalho já foi consumido e não aparece como dado.
aluno["nota"]
O valor pelo nome da coluna, e não pela posição. Continua sendo texto: float(aluno["nota"]) para fazer contas.

Gravando dicionários: DictWriter

Os nomes das colunas (field names, "nomes dos campos"), na ordem em que vão aparecer no arquivo. É obrigatório: o escritor precisa saber quais chaves procurar em cada dicionário.

4. Por que newline=""?

Todos os open desta aula têm newline="". É a recomendação da documentação oficial do módulo csv, e o motivo aparece quando se olha o arquivo gravado com cat -A, que mostra os caracteres invisíveis:

$ head -n 1 estoque.csv | cat -A
produto,preco,estoque^M$

O $ é o fim da linha, e o ^M antes dele é um caractere a mais, o \r ("retorno de carro"). O escritor de CSV termina cada linha com \r\n, que é o que o padrão do CSV pede e o que o Excel espera. Ou seja: o módulo csv já cuida das quebras de linha sozinho. O newline="" diz ao open: "não mexa nelas, deixe passar como estão".

Sem ele, o open também tenta "ajudar" com as quebras de linha, e os dois ajudando ao mesmo tempo atrapalham:

  • No Windows, gravando: o open troca cada \n por \r\n, e o fim de linha vira \r\r\n. No Excel, aparece uma linha em branco entre cada linha. (No Linux da Ana o open não faz essa troca, por isso o erro não aparece aqui; mas o seu programa pode rodar no Windows de alguém.)
  • Em qualquer sistema, lendo: um valor entre aspas pode ter uma quebra de linha dentro (um endereço em duas linhas, por exemplo). Sem newline="", o open altera essa quebra antes de o leitor ver.
A regra para guardar

Abriu um arquivo para usar com o módulo csv? Escreva newline="" e encoding="utf-8". Sempre, lendo ou gravando.

5. O CSV do Excel brasileiro: ponto e vírgula

No Brasil, a vírgula já tem dono: é a vírgula decimal (8,5). Por isso o Excel e o LibreOffice em português, quando salvam um CSV, separam as colunas com ponto e vírgula. A mesma tabela de notas, salva pela professora no Excel, chega assim:

$ cat notas_excel.csv
nome;turma;nota
Bia;A;8,5
Caio;B;6,0
Duda;A;9,5
Enzo;B;7,0

Duas diferenças: o separador é ; e as notas têm vírgula. Para o separador, todo leitor e escritor do módulo aceita a opção delimiter ("delimitador", o caractere que separa as colunas). Para a vírgula decimal, troque por ponto antes de converter:

import csv

with open("notas_excel.csv", newline="", encoding="utf-8") as arquivo:
    alunos = list(csv.DictReader(arquivo, delimiter=";"))

soma = 0
for aluno in alunos:
    nota = float(aluno["nota"].replace(",", "."))
    print(f"{aluno['nome']}: {nota}")
    soma = soma + nota

media = soma / len(alunos)
print(f"Média: {media:.2f}".replace(".", ","))

$ python3 excel.py
Bia: 8.5
Caio: 6.0
Duda: 9.5
Enzo: 7.0
Média: 7,75
delimiter=";"
"As colunas estão separadas por ponto e vírgula." Vale também para csv.reader, csv.writer e csv.DictWriter.
list(csv.DictReader(…))
Lê todas as linhas de uma vez numa lista, para poder usar depois de fechar o arquivo (e saber quantos alunos são com len).
aluno["nota"].replace(",", ".")
Troca a vírgula decimal pelo ponto: "8,5" vira "8.5", que o float entende.
.replace(".", ",")
No fim, o caminho de volta: mostra a média no jeito brasileiro.

Os acentos e o utf-8-sig

Quando a professora escolhe no Excel "CSV UTF-8", o arquivo ganha três bytes invisíveis bem no começo, chamados BOM (byte order mark, uma "marca" que avisa que o arquivo é UTF-8). Lido com encoding="utf-8", o BOM gruda no nome da primeira coluna, e aluno["nome"] não acha nada (veja em Quando dá errado). A solução é a codificação "utf-8-sig", que é o UTF-8 que sabe pular o BOM se ele existir (e lê normalmente se não existir):

import csv

with open("notas_bom.csv", newline="", encoding="utf-8-sig") as arquivo:
    for aluno in csv.DictReader(arquivo, delimiter=";"):
        print(aluno["nome"], aluno["nota"])

$ python3 bom2.py
Bia 8,5
Caio 6,0

E no caminho contrário, para gravar um CSV que o Excel em português abra com as colunas separadas e os acentos certos, use o ponto e vírgula e grave com o BOM:

import csv

with open("para_excel.csv", "w", newline="", encoding="utf-8-sig") as arquivo:
    escritor = csv.writer(arquivo, delimiter=";")
    escritor.writerow(["produto", "preço"])
    escritor.writerow(["café", "18,90"])

print("Gravei para_excel.csv")

$ python3 grava_excel.py
Gravei para_excel.csv
$ file para_excel.csv                   « o comando file descreve o arquivo
para_excel.csv: Unicode text, UTF-8 (with BOM) text, with CRLF line terminators

O file confirmou: UTF-8 com BOM, e linhas terminadas em \r\n (CRLF), como o Excel gosta.

with open("clientes.csv", encoding="utf-8") as arquivo:
    for linha in arquivo:

CSV do Excel lido sem delimiter=";": KeyError 
import csv

with open("notas_excel.csv", newline="", encoding="utf-8") as arquivo:
    for aluno in csv.DictReader(arquivo):
        print(aluno)
        print(aluno["nota"])

Traceback (most recent call last):
  File "/home/ana/excel_sem.py", line 6, in <module>
    print(aluno["nota"])
          ~~~~~^^^^^^^^
KeyError: 'nota'

O print(aluno) da linha 5 conta a história toda. Procurando vírgulas, o leitor achou uma só: a do 8,5! Então o cabeçalho inteiro, 'nome;turma;nota', virou o nome de uma coluna, com o valor 'Bia;A;8', e o 5 que sobrou depois da vírgula foi para uma chave None ("valores a mais, sem coluna"). Na linha 6, KeyError: 'nota': "chave não encontrada". Não existe nenhuma coluna chamada nota. Como consertar: csv.DictReader(arquivo, delimiter=";").

Vírgula decimal no float: ValueError

Resumo

  • CSV é uma tabela em texto: uma linha por registro, uma vírgula entre as colunas, e o cabeçalho na primeira linha.
  • Abra sempre com newline="" e encoding="utf-8": o módulo csv cuida das quebras de linha.
  • csv.reader dá listas; next(leitor) pula o cabeçalho. csv.DictReader dá dicionários com as chaves do cabeçalho.
  • Todo valor lido é texto: converta com int() ou float().
  • csv.writer + writerow/writerows gravam listas; csv.DictWriter(…, fieldnames=…) + writeheader() gravam dicionários. As aspas para valores com vírgula aparecem sozinhas.
  • Excel brasileiro: delimiter=";", vírgula decimal (.replace(",", ".")) e encoding="utf-8-sig" para o BOM.
  • O leitor só anda para a frente e só funciona com o arquivo aberto: para usar depois, list(leitor).
