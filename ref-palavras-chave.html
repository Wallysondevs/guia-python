Python Palavras-chave

As palavras-chave (keywords) são as palavras que fazem parte da própria língua do Python: if, for, def, return… São como as palavras de um formulário que você não pode apagar: elas já têm um papel fixo, e por isso não podem ser usadas como nome de variável, função ou classe. No Python 3.14 são 35, mais 4 palavras-chave "suaves" que só são especiais em certos lugares. Esta página lista todas, com o que cada uma faz e o link para a aula. A regra dos nomes está na aula Nomes de Variáveis.

Como ler as tabelas
  • Exemplo é um trecho curto de programa; Resultado é o que o Python 3.14.4 mostrou no computador da Ana ao rodá-lo.
  • As palavras-chave são escritas sempre em minúsculas, menos três: True, False e None, que começam com maiúscula. true (minúsculo) não é nada para o Python: é um nome qualquer, e print(true) dá NameError: name 'true' is not defined. Did you mean: 'True'?.

A lista oficial, perguntada ao Python

O módulo keyword ("palavra-chave") guarda a lista oficial. kwlist são as palavras reservadas; softkwlist, as suaves:

import keyword

print(keyword.kwlist)
print(len(keyword.kwlist))
print(keyword.softkwlist)

$ python3 kw.py

O mesmo módulo responde se uma palavra é reservada: keyword.iskeyword("for") deu True, keyword.iskeyword("print") deu False (print é uma função, não uma palavra-chave) e keyword.iskeyword("match") deu False, porque match é suave: quem responde True para ela é keyword.issoftkeyword("match").

As palavras-chave suaves: match, case, type e _

As palavras-chave suaves (soft keywords) só são especiais em certo lugar. Fora dele, são nomes comuns. Elas entraram depois que muita gente já tinha variáveis chamadas match ou type; tornar essas palavras proibidas quebraria esses programas.

PalavraEspecial quando…DesdeAula
matchcomeça uma linha match valor: (escolher entre vários casos)3.10match e case
caseestá dentro de um match: case padrão:3.10match e case
_é o padrão de um case _:, o "qualquer outra coisa"3.10match e case
typecomeça uma linha type Nome = … (dar nome a um tipo)3.12Dicas de Tipo

As três primeiras trabalhando juntas:

def ponto(p):
    match p:
        case (0, 0):
            return "origem"
        case (x, 0):
            return f"no eixo x, em {x}"
        case _:
            return "outro lugar"

print(ponto((0, 0)), ponto((3, 0)), ponto((1, 2)))

$ python3 ponto.py
origem no eixo x, em 3 outro lugar

E a prova de que, fora desses lugares, elas são nomes comuns: este trecho rodou sem erro e mostrou 5 e depois ok texto 9.

match = 5
print(match)
case = "ok"; type = "texto"; _ = 9
print(case, type, _)

Poder não quer dizer dever: type também é o nome da função type(), que descobre o tipo de um valor, e uma variável type a esconde (veja o quadro abaixo). Já a frase type Nota = float não atrapalha a função: depois dela, print(type(7.5)) continuou mostrando <class 'float'>, e print(Nota.__value__) mostrou <class 'float'>.

O que não é palavra-chave (mas parece)

print, input, len, list, str, int, type, sum, max… são funções embutidas, não palavras-chave. O Python deixa você usar esses nomes para uma variável, e é justamente esse o perigo: a variável toma o lugar da função.

Uma variável chamada print 
print = "Bom dia"
print("Olá, Ana!")

$ python3 sombra.py
Traceback (most recent call last):
  File "/home/ana/sombra.py", line 2, in <module>
    print("Olá, Ana!")
    ~~~~~^^^^^^^^^^^^^
TypeError: 'str' object is not callable

A linha 1 é aceita: print não é reservada, e virou o texto "Bom dia". Na linha 2, print(…) tenta "chamar" esse texto como se fosse função, e o Python reclama: 'str' object is not callable ("um objeto str não pode ser chamado"). O mesmo acontece com uma variável list, sum ou input. Escolha nomes que descrevem o conteúdo: saudacao, compras, total.

Quando dá errado: uma palavra-chave como nome

A Ana quis guardar a turma numa variável chamada class:

class como nome de variável 
aluna = "Ana"
class = "3A"
print(aluna, class)

$ python3 turma.py
  File "/home/ana/turma.py", line 2
    class = "3A"
          ^
SyntaxError: invalid syntax
  • Não há a linha Traceback: o erro foi achado na leitura do arquivo, e nenhuma linha rodou (nem a 1).
  • line 2 e o ^ embaixo do =: depois de class o Python esperava o nome de uma classe, e encontrou um sinal de igual.
  • SyntaxError: invalid syntax: "sintaxe inválida". A mensagem não diz "palavra reservada"; quando um invalid syntax aparece numa linha que parece certa, confira se algum nome dela está na lista desta página.

O conserto é trocar o nome: turma = "3A".

for palavra in ["for", "print", "match", "True", "lista"]:

Resumo

  • O Python 3.14 tem 35 palavras-chave (keyword.kwlist) e 4 suaves (keyword.softkwlist: match, case, type, _).
  • Uma palavra-chave não pode ser nome de variável, função ou classe: o resultado é SyntaxError, antes de o programa rodar.
  • As suaves só são especiais no lugar delas (match …:, case …:, type X = …); fora dali, são nomes comuns.
  • Só True, False e None começam com maiúscula.
  • print, list, input, type não são palavras-chave: o Python aceita esses nomes para variáveis, mas a variável esconde a função. Evite.
  • Dúvida? keyword.iskeyword("palavra") responde, e help("for") explica cada uma.
