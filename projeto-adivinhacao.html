Projeto Jogo de Adivinhação

O computador pensa num número de 1 a 100 e você tenta adivinhar. A cada palpite, ele diz "mais alto" ou "mais baixo", até você acertar ou as tentativas acabarem. É um jogo pequeno, mas tem tudo o que um programa de verdade tem: um sorteio, um laço, decisões, uma conta de tentativas e a obrigação de não quebrar quando alguém digita "sete" no lugar de 7.

Você vai praticar
  • Sortear números com o módulo random (randint e a semente seed) e usar import.
  • Converter o palpite com int() e comparar com < e ==.
  • Repetir até acertar com while.
  • Contar e limitar as tentativas com for, range(), break e o else dos laços.
  • Validar o palpite com try e except e continue.
  • Organizar a partida numa função que devolve um resultado com return, e guardar o recorde.

Antes de tudo: sorteio e semente

O sorteio vem do módulo random ("aleatório"), que faz parte do Python: basta um import random no começo do programa. A função random.randint(1, 100) sorteia um número inteiro de 1 a 100, com o 1 e o 100 incluídos. No modo interativo:

$ python3
Python 3.14.4 (main, Aug 20 2026, 10:41:58) [GCC 15.2.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> import random
>>> random.randint(1, 100)
81
>>> random.randint(1, 100)
49
>>> random.seed(42)
>>> random.randint(1, 100)
82
>>> random.randint(1, 100)
15
>>> random.seed(42)
>>> random.randint(1, 100)
82
>>> exit()

Os dois primeiros sorteios deram 81 e 49 no computador da Ana; no seu, vão dar outros números, e a cada vez outros. Agora repare no random.seed(42): depois dele, o primeiro sorteio deu 82, o segundo 15, e quando a Ana chamou random.seed(42) de novo, o sorteio voltou a dar 82.

O que é a semente (seed)

O computador não "joga dados" de verdade: ele calcula uma sequência de números que parecem aleatórios, a partir de um número inicial, a semente (em inglês, seed). Sem seed, o Python escolhe uma semente diferente a cada execução, e o jogo é imprevisível. Com random.seed(42), a semente é sempre 42, e a sequência é sempre a mesma: 82, 15, 4, 95…

Isso é ótimo para testar: se o número secreto é sempre 82, dá para conferir se o programa responde certo. Por isso, todas as missões desta página começam com random.seed(42), e o número secreto delas é sempre 82 (e, numa segunda partida, 15). No jogo de verdade, a linha do seed sai: senão a Ana decoraria a resposta.

import random

random.seed(42)
print(random.randint(1, 100), random.randint(1, 100), random.randint(1, 100))

$ python3 semente.py
82 15 4
$ python3 semente.py
82 15 4

Versão 2 · Dicas até acertar

Agora o jogo fica de verdade: enquanto o palpite for diferente do número secreto, o programa dá uma dica e pede outro palpite. "Enquanto" é while.

import random

secreto = random.randint(1, 100)
print("Pensei num número de 1 a 100. Tente adivinhar!")

palpite = int(input("Seu palpite: "))
while palpite != secreto:
    if palpite < secreto:
        print("Mais alto!")
    else:
        print("Mais baixo!")
    palpite = int(input("Seu palpite: "))

print(f"Acertou! O número era {secreto}.")
LinhaO que faz
palpite = int(input(…)) (antes do laço)O primeiro palpite. Ele precisa existir antes do while, porque a condição do laço usa palpite.
while palpite != secreto:"Enquanto o palpite for diferente do secreto". O != é "diferente de". Se a pessoa acertar de primeira, o laço nem roda.
if palpite < secreto:Palpite menor que o secreto: a resposta está mais para cima.
palpite = int(input(…)) (dentro do laço)O próximo palpite. É ele que muda a condição; sem esta linha, o laço repetiria a mesma dica para sempre (veja o cenário abaixo).
print(f"Acertou! …")Fora do laço: só chega aqui quando palpite != secreto ficar falso, ou seja, quando acertar.

A estratégia da Ana: sempre o meio

Repare nos palpites: 50 (o meio de 1 a 100), depois 75 (o meio de 51 a 100), depois 88… A cada dica, ela chuta o meio do que sobrou, e a quantidade de números possíveis cai pela metade: 100, 50, 25, 12, 6, 3, 1. Com essa estratégia (em programação ela se chama busca binária), 7 palpites sempre bastam para 100 números, porque 2 elevado a 7 é 128, mais que 100. É por isso que a versão 3 vai dar 7 tentativas.

Esquecer o novo palpite dentro do laço

Se a última linha de dentro do while (o segundo palpite = int(input(…))) sumir, o palpite nunca muda. A condição palpite != secreto continua verdadeira para sempre, e o programa fica escrevendo "Mais alto!" sem parar, sem nunca mais perguntar nada. É um laço infinito. Para interromper, aperte Ctrl+C (o Python mostra um KeyboardInterrupt). Regra prática: dentro de um while, sempre tem de haver alguma linha que mude a condição.

Versão 3 · Tentativas contadas e limitadas

Com tentativas infinitas, ninguém perde. A versão 3 dá 7 tentativas e mostra em qual a pessoa está. Quando já se sabe quantas vezes no máximo algo vai se repetir, o laço natural é o for com range().

import random

MAXIMO = 7
secreto = random.randint(1, 100)
print(f"Pensei num número de 1 a 100. Você tem {MAXIMO} tentativas.")

for tentativa in range(1, MAXIMO + 1):
    palpite = int(input(f"Tentativa {tentativa}/{MAXIMO}: "))
    if palpite == secreto:
        print(f"Acertou em {tentativa} tentativa(s)!")
        break
    elif palpite < secreto:
        print("Mais alto!")
    else:
        print("Mais baixo!")
else:
    print(f"Suas tentativas acabaram. O número era {secreto}.")
MAXIMO = 7
O limite num lugar só, em MAIÚSCULAS (o costume para um valor fixo). Para mudar a dificuldade, basta mudar esta linha.
for tentativa in range(1, MAXIMO + 1):
A variável tentativa vale 1, 2, 3… até 7. O range(1, 8) não inclui o 8: por isso o + 1 (veja range()).
f"Tentativa {tentativa}/{MAXIMO}: "
A pergunta mostra o número da tentativa: Tentativa 3/7:.
break
Acertou: sai do for na hora, sem gastar as tentativas que sobraram.
else: (alinhado com o for)
O else de um laço roda só se o laço terminar sem break, ou seja, se as 7 tentativas passaram sem acerto. É exatamente o "perdeu". Repare na indentação: ele está na mesma coluna do for, e não do if. Mais em else nos Laços.

Versão 4 · Palpite validado

A leitura do palpite vira uma função, ler_palpite, que só devolve um palpite quando ele é um inteiro e está entre 1 e 100. Palpite inválido não gasta tentativa: a função simplesmente pergunta de novo.

import random

MENOR = 1
MAIOR = 100
MAXIMO = 7


def ler_palpite(pergunta):
    """Pergunta até a pessoa digitar um inteiro entre MENOR e MAIOR."""
    while True:
        texto = input(pergunta).strip()
        try:
            palpite = int(texto)
        except ValueError:
            print(f'"{texto}" não é um número inteiro.')
            continue
        if MENOR <= palpite <= MAIOR:
            return palpite
        print(f"O número é de {MENOR} a {MAIOR}.")


secreto = random.randint(MENOR, MAIOR)
print(f"Pensei num número de {MENOR} a {MAIOR}. Você tem {MAXIMO} tentativas.")

for tentativa in range(1, MAXIMO + 1):
    palpite = ler_palpite(f"Tentativa {tentativa}/{MAXIMO}: ")
    if palpite == secreto:
        print(f"Acertou em {tentativa} tentativa(s)!")
        break
    elif palpite < secreto:
        print("Mais alto!")
    else:
        print("Mais baixo!")
else:
    print(f"Suas tentativas acabaram. O número era {secreto}.")
MENOR = 1 e MAIOR = 100
Os limites do sorteio também viraram constantes: o randint, a mensagem e a validação usam os mesmos valores. Para jogar de 1 a 1000, muda-se um lugar só.
try: palpite = int(texto)
Tenta converter. Se der ValueError, o Python pula para o except.
continue
"Continuar": volta direto para o começo do while, pulando o resto da volta. Sem ele, o programa seguiria para o if com uma variável palpite que não foi criada (veja break e continue).
if MENOR <= palpite <= MAIOR:
Uma comparação "encadeada": 1 <= palpite <= 100 quer dizer "palpite maior ou igual a 1 e menor ou igual a 100", como na matemática. Poucas linguagens deixam escrever assim.
return palpite
Palpite bom: devolve e sai da função (e do while True).
print(f"O número é de …")
Só chega aqui um inteiro fora da faixa. Depois do aviso, o while True pergunta de novo.

Versão 5 · Várias partidas e recorde

Para jogar de novo sem rodar o programa outra vez, a partida inteira vira uma função, jogar(), e o programa principal chama essa função dentro de um while True. A função devolve o resultado da partida: quantas tentativas a pessoa usou, ou None se ela perdeu. Com isso, o programa principal guarda o recorde: o menor número de tentativas numa vitória.

Formas diferentes de fazer

Contar as tentativas: for ou while

A versão 3 usou for com break e else. O mesmo jogo com while precisa de um contador feito à mão (abaixo, só o trecho do laço):

tentativa = 1
acertou = False
while tentativa <= MAXIMO and not acertou:
    palpite = int(input(f"Tentativa {tentativa}/{MAXIMO}: "))
    if palpite == secreto:
        acertou = True
    # … as dicas …
    tentativa += 1

Funciona, mas há mais coisas para lembrar: criar o contador, somar 1 no fim de cada volta (esquecer o tentativa += 1 dá um laço infinito) e criar uma variável acertou só para sair. O for faz a contagem sozinho.

Sortear o número

O randrange(1, 101) funciona como o range: o fim (101) fica de fora. Com a mesma semente, ele dá o mesmo 82 que o randint(1, 100), porque, por dentro, o randint(a, b) chama o randrange(a, b + 1).

FormaQuando usar
for tentativa in range(1, MAXIMO + 1) com break/elseNúmero máximo de voltas conhecido. O contador vem pronto.
while com contadorQuando a condição de parar é mais complicada que "no máximo N vezes". Cuidado com o contador.
while palpite != secretoRepetir até acontecer algo, sem limite (versão 2).
random.randint(1, 100)Sortear um inteiro com os dois extremos incluídos. O mais fácil de ler.
random.randrange(1, 101)Mesma coisa, no estilo do range (o fim fica de fora). Aceita um passo: randrange(0, 101, 10) sorteia 0, 10, 20…

Ideias para continuar

  • Níveis de dificuldade: antes de começar, pergunte "fácil, médio ou difícil" e mude MAIOR e MAXIMO (1 a 10 com 4 tentativas, 1 a 100 com 7, 1 a 1000 com 10).
  • Avise quando a pessoa repetir um palpite que já deu (guarde os palpites numa lista).
  • Dica de "quente" e "frio": se a diferença entre o palpite e o secreto for menor que 5, diga "Está quente!" (use abs(), veja Funções Embutidas).

Resumo

  • import random e random.randint(1, 100) sorteiam um inteiro de 1 a 100, com os dois extremos.
  • random.seed(42) fixa a semente: a sequência sorteada passa a ser sempre a mesma. Ótimo para testar; no jogo de verdade, sem semente.
  • O texto "82" não é igual ao número 82: converta o palpite com int().
  • while repete "até acontecer"; for com range repete "no máximo N vezes" e já conta as voltas.
  • O else de um laço roda só quando o laço termina sem break: é o "perdeu" do jogo.
  • try/except com continue pede de novo sem gastar tentativa; MENOR <= x <= MAIOR confere a faixa.
  • Uma função que devolve o resultado (return tentativa ou None) deixa o programa principal cuidar do recorde.
  • Nunca dê a um arquivo seu o nome de um módulo do Python (random.py).
