Python Módulos da Biblioteca Padrão

O Python vem com "pilhas incluídas": junto com ele, chegam centenas de módulos prontos, a chamada biblioteca padrão (em inglês, standard library). Para usar um deles basta um import, sem instalar nada (aula Módulos e import). Esta página reúne os mais úteis no dia a dia, agrupados por assunto, com uma linha sobre o que cada um faz, um exemplo com o resultado de verdade e o link para a aula, quando há uma. A lista completa está na documentação oficial.

Como ler as tabelas
  • Cada exemplo supõe que o módulo já foi importado: o exemplo math.sqrt(16) vem depois de um import math.
  • O resultado é o que o Python 3.14.4 respondeu no computador da Ana, escrito como o modo interativo mostra (textos entre aspas).
  • Quando o resultado muda a cada execução (sorteios, hora, nomes de pasta temporária), a tabela avisa.
  • A marca (não no editor) quer dizer que aquilo não funciona no editor do guia, que roda o Python dentro do navegador. No terminal, funciona.

Pule direto para o grupo:

  • Números e contas: math, random, statistics, decimal, fractions
  • Textos: string, re, textwrap, unicodedata, difflib
  • Datas e tempo: datetime, time, calendar, zoneinfo
  • Coleções e funções: collections, itertools, functools, operator, heapq, bisect, copy, dataclasses, enum, typing
  • Arquivos e pastas: pathlib, os, shutil, glob, tempfile, zipfile, gzip
  • Formatos de dados: json, csv, sqlite3, tomllib, base64
  • Sistema e programas: sys, os, subprocess, argparse, logging, platform, shlex, threading, asyncio
  • Internet e segurança: urllib, html, http.server, hashlib, secrets, uuid
  • Testes e depuração: unittest, doctest, pdb, timeit, keyword
  • Novidades do Python 3.14: compression.zstd, annotationlib, string.templatelib

Experimente

Missão: use o statistics para mostrar a média das notas (Média: 7.75) e o Counter do collections para mostrar o tamanho de camiseta mais pedido (Mais pedido: M). Não esqueça os import.

notas = [7.5, 8.0, 6.5, 9.0]
tamanhos = ["P", "M", "M", "G"]

print("Média:", 0)
print("Mais pedido:", "?")

import statistics
from collections import Counter

notas = [7.5, 8.0, 6.5, 9.0]
tamanhos = ["P", "M", "M", "G"]

print("Média:", statistics.mean(notas))
print("Mais pedido:", Counter(tamanhos).most_common(1)[0][0])
