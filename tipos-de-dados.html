Python Tipos de Dados

Nas aulas anteriores apareceram valores bem diferentes: o texto "Ana", o número 29, o preço 7.5. Você já viu que "2" + "3" dá "23" e que 2 + 3 dá 5. A diferença está no tipo de cada valor: todo valor no Python tem um tipo, e é o tipo que decide o que dá para fazer com ele. Esta aula é o mapa dos tipos que você vai usar o tempo todo.

Você vai aprender

  • Os cinco tipos básicos: str (texto), int (inteiro), float (decimal), bool (verdadeiro/falso) e None (nada).
  • Como o Python descobre o tipo só pela escrita do valor.
  • Que quem tem tipo é o valor, e não a variável.
  • Por que o mesmo + soma números e junta textos.
  • Um primeiro olhar nas coleções: listas, tuplas, dicionários e conjuntos.
  • Os TypeError reais de misturar tipos que não combinam.

Os programas desta aula foram rodados com o Python 3.14 na máquina fictícia da Ana (usuária ana, computador notebook), com python3 arquivo.py.

A ideia: cada coisa no seu tipo de embalagem

Na padaria, cada coisa vem num tipo de embalagem: o leite em caixa, os ovos em bandeja, o pão em saco de papel. A embalagem diz o que dá para fazer: você despeja o leite, mas não despeja os ovos; você conta os ovos, mas não conta o leite (você mede). Ninguém tenta fatiar a caixa de leite.

No Python, o tipo é a embalagem do valor. Com um número (int), dá para fazer conta. Com um texto (str), dá para juntar, procurar uma letra, pôr em maiúsculas. Quando você tenta fazer com um valor uma coisa que o tipo dele não permite, o Python para e avisa com um TypeError, "erro de tipo".

A função type() responde qual é o tipo de um valor; a resposta vem no formato <class 'nome-do-tipo'> ("classe" é o nome que o Python dá a um tipo). Ela é o assunto da próxima aula, Descobrindo o Tipo. Agora, cada tipo com calma.

int — 29
Números sem ponto decimal. Não têm limite de tamanho: 2 ** 100 (2 elevado a 100) dá 1267650600228229401496703205376, sem erro. Aula: Números.
float — 1.65
Números com ponto. Basta o ponto para ser float: 3.0 é float, 3 é int. As contas com float às vezes têm um errinho na última casa (0.1 + 0.2 dá 0.30000000000000004), explicado em Números.
bool — True

None — None
"Nada", "ainda não tem". A Ana não tem apelido, então apelido = None. Não é zero nem texto vazio: é a ausência de valor. Aula: O Valor None.

2. O Python descobre o tipo pela escrita

Você nunca disse ao Python "isto é um inteiro". Ele descobre olhando como o valor foi escrito:

Para o Python, 7, 7.0 e "7" são três coisas diferentes. Os dois números valem o mesmo; o texto, não:

print(7 == 7)
print("7" == 7)

O == pergunta "é igual?" (aula Comparações). O texto "7" não é igual ao número 7: um é um desenho do algarismo, o outro é a quantidade sete.

3. Quem tem tipo é o valor, não a variável

Na aula Variáveis, a variável era uma etiqueta presa a um valor. O tipo pertence ao valor. A etiqueta pode ser presa a um valor de outro tipo, e aí o tipo "da variável" muda junto:

caixa = 10
print(caixa, type(caixa))
caixa = "dez"
print(caixa, type(caixa))

$ python3 td-mudar.py
10 <class 'int'>
dez <class 'str'>

Por isso se diz que o Python tem tipagem dinâmica: o tipo é conferido na hora em que o programa roda, valor por valor. E também tipagem forte: o Python não converte um tipo em outro por conta própria quando eles não combinam; ele prefere dar erro (seção 4). Em C ou Java, ao contrário, a variável tem um tipo fixo, declarado antes.

E quando o valor veio com o tipo errado?

Acontece o tempo todo: o input() sempre devolve str (aula input()). Para transformar um tipo em outro existem int(), float(), str() e bool(), assunto da aula Conversão de Tipos.

Quando dá errado

Número + texto 
print(4 + "3")

$ python3 td-err1.py
Traceback (most recent call last):
  File "/home/ana/td-err1.py", line 1, in <module>
    print(4 + "3")
          ~~^~~~~
TypeError: unsupported operand type(s) for +: 'int' and 'str'

"Tipos de operando não suportados para +: int e str". Um operando é cada valor de uma conta. O Python não sabe somar um número com um texto, e não tenta adivinhar se você queria 7 ou "43". Com o texto na frente ("3" + 4), a mensagem muda para a que você viu em print(), can only concatenate str (not "int") to str, mas o problema é o mesmo. Como consertar: deixe os dois do mesmo tipo: 4 + 3 (números) ou "4" + "3" (textos).

Subtrair textos 
print("pão" - "p")

$ python3 td-err2.py
Traceback (most recent call last):
  File "/home/ana/td-err2.py", line 1, in <module>
    print("pão" - "p")
          ~~~~~~^~~~~
TypeError: unsupported operand type(s) for -: 'str' and 'str'

Desta vez os dois são do mesmo tipo, e mesmo assim deu erro: o tipo str sabe juntar (+) e repetir (*), mas não sabe "tirar" (-). Para tirar letras de um texto existe o método replace() (aula Métodos de Texto).

Repetir um texto um número quebrado de vezes 
print("ab" * 2.5)

$ python3 td-err3.py
Traceback (most recent call last):
  File "/home/ana/td-err3.py", line 1, in <module>
    print("ab" * 2.5)
          ~~~~~^~~~~
TypeError: can't multiply sequence by non-int of type 'float'

"Não dá para multiplicar uma sequência por um não inteiro do tipo float". Repetir um texto "duas vezes e meia" não faz sentido; o número de repetições tem de ser um int. (Uma sequência é um valor com itens em ordem, como o texto, que é uma sequência de letras.)

Pedir algo que o tipo não tem 
print(len(42))

$ python3 td-err4.py
Traceback (most recent call last):
  File "/home/ana/td-err4.py", line 1, in <module>
    print(len(42))
          ~~~^^^^
TypeError: object of type 'int' has no len()

A função len() (de length, "comprimento") conta os itens de um valor: len("Ana") dá 3, três letras. Um número não tem itens para contar: "um objeto do tipo int não tem len()". Se você queria contar os algarismos, o número precisaria virar texto antes: len(str(42)) (aula Conversão de Tipos).

Resumo

  • Todo valor tem um tipo, e o tipo decide o que dá para fazer com ele.
  • Os básicos: str (texto, entre aspas), int (inteiro), float (com ponto), bool (True/False) e None (nada).
  • O Python descobre o tipo pela escrita: 7, 7.0 e "7" são três tipos diferentes.
  • Quem tem tipo é o valor; a variável só aponta para ele e pode passar a apontar para um valor de outro tipo.
  • + soma números e junta textos; * multiplica números e repete textos; / sempre dá float.
  • int e float se misturam nas contas; texto e número não: TypeError.
  • Coleções guardam vários valores: list, tuple, dict, set (aulas no Nível 2).
