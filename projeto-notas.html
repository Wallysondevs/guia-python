Python Projeto: Notas da Turma

A professora da escola do bairro guarda as notas da turma numa planilha e, todo bimestre, faz as contas à mão: a média de cada aluno, quem passou, quem vai para a recuperação. A Ana se ofereceu para automatizar isso. A planilha é exportada como CSV (um arquivo de texto com os valores separados por vírgulas, aula Arquivos CSV), e o programa vai ler esse arquivo, calcular tudo, mostrar um relatório arrumado e gravar o resultado num CSV novo, pronto para abrir na planilha. Quatro versões, uma novidade por vez.

Neste projeto você vai usar
  • open e with e o módulo csv (DictReader e DictWriter).
  • Dicionários e listas, com float() para transformar texto em número.
  • Funções com return, e if e else para a situação.
  • f-strings com alinhamento (Formatação) para o relatório.
  • sort com lambda para ordenar pela média, e list comprehension para contar os aprovados.

O que vamos construir

A pasta do projeto tem o arquivo de notas que a professora exportou:

nome,turma,nota1,nota2,nota3
Bia,A,8.0,9.5,7.0
Caio,B,6.0,5.5,5.0
Duda,A,9.0,10.0,9.5
Enzo,B,7.0,7.0,7.0
Gabi,A,4.5,6.0,5.5
Hugo,B,10.0,8.5,9.0

A primeira linha é o cabeçalho: o nome de cada coluna. Cada linha seguinte é um aluno, com a turma e as três notas do bimestre. A regra da escola: média 7 ou mais, aprovado; abaixo de 7, recuperação. Esta é a versão final rodando no computador da Ana:

------------------------------------

Hugo       B      9.17  aprovado
Bia        A      8.17  aprovado
Enzo       B      7.00  aprovado
Caio       B      5.50  recuperação
Gabi       A      5.33  recuperação
------------------------------------
Média da turma: 7.44
Aprovados: 4 de 6
Gravei resultado.csv
$ cat resultado.csv
nome,turma,media,situacao
Duda,A,9.50,aprovado
Hugo,B,9.17,aprovado
Bia,A,8.17,aprovado
Enzo,B,7.00,aprovado
Caio,B,5.50,recuperação
Gabi,A,5.33,recuperação

(O cat mostra o conteúdo de um arquivo de texto no terminal.) As quatro versões:

  1. Ler o CSV com csv.DictReader.
  2. Média e situação, em funções.
  3. O relatório, alinhado e ordenado pela média.
  4. Gravar o resultado.csv com csv.DictWriter.

Antes de começar

Crie a pasta do projeto, entre nela e salve lá o notas.csv de cima (num editor de texto, ou exportando da planilha como "CSV separado por vírgulas"). O programa vai se chamar notas.py, na mesma pasta:

$ mkdir -p projetos/notas
$ cd projetos/notas

As caixas Experimente deste projeto têm duas abas: o programa (main.py) e o notas.csv, que fica na mesma pasta do programa. Você pode mexer nas notas da aba do CSV e rodar de novo para ver o resultado mudar.

import csv
O módulo da biblioteca padrão que entende arquivos CSV: separa as colunas, lida com aspas e vírgulas dentro dos valores.
open("notas.csv", newline="", encoding="utf-8")
Abre o arquivo para leitura. O newline="" é a recomendação da documentação para arquivos CSV (o módulo csv cuida das quebras de linha sozinho), e o encoding="utf-8" garante que os acentos sejam lidos certo. A aula Arquivos CSV explica os dois.
csv.DictReader(arquivo)
Lê cada linha como um dicionário, usando o cabeçalho como chaves. O cabeçalho em si não vira aluno.
list(…)
Junta todos os dicionários numa lista, para usar depois que o with fechar o arquivo.
aluno["nome"]
Cada valor se pega pelo nome da coluna, e não pela posição. Se a professora mudar a ordem das colunas, o programa continua certo.

Versão 2 · Média e situação

Versão 3 · O relatório

A professora quer imprimir uma tabela: os alunos do melhor para o pior, com as colunas alinhadas, e um resumo da turma no fim. A média e a situação passam a ser guardadas em cada aluno, para o relatório e a ordenação usarem.

import csv


def ler_alunos(caminho):
    alunos = []
    with open(caminho, newline="", encoding="utf-8") as arquivo:
        for linha in csv.DictReader(arquivo):
            notas = [float(linha["nota1"]), float(linha["nota2"]), float(linha["nota3"])]
            alunos.append({"nome": linha["nome"], "turma": linha["turma"], "notas": notas})
    return alunos


def media(notas):
    return sum(notas) / len(notas)


def situacao(m):
    if m >= 7:
        return "aprovado"
    return "recuperação"


def relatorio(alunos):
    print(f"{'Aluno':<8}{'Turma':^7}{'Média':>7}  Situação")
    print("-" * 36)
    for aluno in alunos:
        print(f"{aluno['nome']:<8}{aluno['turma']:^7}{aluno['media']:>7.2f}  {aluno['situacao']}")
    print("-" * 36)
    aprovados = [a for a in alunos if a["situacao"] == "aprovado"]
    media_turma = sum(a["media"] for a in alunos) / len(alunos)
    print(f"Média da turma: {media_turma:.2f}")
    print(f"Aprovados: {len(aprovados)} de {len(alunos)}")


alunos = ler_alunos("notas.csv")
for aluno in alunos:
    aluno["media"] = media(aluno["notas"])
    aluno["situacao"] = situacao(aluno["media"])

alunos.sort(key=lambda a: a["media"], reverse=True)
relatorio(alunos)

As partes novas, uma por uma

aluno["media"] = media(aluno["notas"])
Acrescenta duas chaves em cada dicionário de aluno, media e situacao, calculadas uma vez só.
alunos.sort(key=lambda a: a["media"], reverse=True)
Ordena a lista pela média. O key diz o que comparar em cada aluno (uma lambda, função de uma linha, aula lambda), e o reverse=True põe a maior primeiro (aula Ordenando Listas).
{'Aluno':<8}
O texto Aluno alinhado à esquerda num espaço de 8 caracteres. O que sobra vira espaço em branco.
{'Turma':^7}
Centralizado em 7 caracteres.
{aluno['media']:>7.2f}
O número alinhado à direita em 7 caracteres, com duas casas. Números alinhados à direita deixam as vírgulas uma embaixo da outra.
"-" * 36
Repete o traço 36 vezes: a linha da tabela (aula Juntar e Repetir Textos).
[a for a in alunos if a["situacao"] == "aprovado"]
Uma lista só com os aprovados (aula List Comprehension); o len dela conta quantos são.
sum(a["media"] for a in alunos)
Soma as médias de todos os alunos, sem criar uma lista no meio.
$ python3 notas.py

------------------------------------

Enzo       B      7.00  aprovado
Caio       B      5.50  recuperação
Gabi       A      5.33  recuperação
------------------------------------
Média da turma: 7.44
Aprovados: 4 de 6

As colunas ficaram alinhadas porque cada campo ocupa sempre o mesmo número de caracteres, seja qual for o nome. (Num nome com mais de 8 letras, o alinhamento quebraria: o f-string nunca corta um texto, só completa os que são menores.)

O fim de linha do CSV

Por padrão, o módulo csv termina cada linha com \r\n (o fim de linha do Windows), como pede a especificação dos arquivos CSV. No terminal isso não aparece, e as planilhas leem sem problema. É por isso que o newline="" é importante também na gravação: sem ele, em alguns sistemas, cada linha ganharia uma quebra a mais.

import csv


def ler_alunos(caminho):
    alunos = []
    with open(caminho, newline="", encoding="utf-8") as arquivo:
        for linha in csv.DictReader(arquivo):
            notas = [float(linha["nota1"]), float(linha["nota2"]), float(linha["nota3"])]
            alunos.append({"nome": linha["nome"], "turma": linha["turma"], "notas": notas})
    return alunos


def media(notas):
    return sum(notas) / len(notas)


def situacao(m):
    if m >= 7:
        return "aprovado"
    return "recuperação"


def relatorio(alunos):
    print(f"{'Aluno':<8}{'Turma':^7}{'Média':>7}  Situação")
    print("-" * 36)
    for aluno in alunos:
        print(f"{aluno['nome']:<8}{aluno['turma']:^7}{aluno['media']:>7.2f}  {aluno['situacao']}")
    print("-" * 36)
    aprovados = [a for a in alunos if a["situacao"] == "aprovado"]
    media_turma = sum(a["media"] for a in alunos) / len(alunos)
    print(f"Média da turma: {media_turma:.2f}")
    print(f"Aprovados: {len(aprovados)} de {len(alunos)}")


def gravar_resultado(alunos, caminho):
    with open(caminho, "w", newline="", encoding="utf-8") as arquivo:
        escritor = csv.DictWriter(arquivo, fieldnames=["nome", "turma", "media", "situacao"])
        escritor.writeheader()
        for aluno in alunos:
            escritor.writerow({
                "nome": aluno["nome"],
                "turma": aluno["turma"],
                "media": f"{aluno['media']:.2f}",
                "situacao": aluno["situacao"],
            })

Formas diferentes de guardar cada aluno

Neste projeto, cada aluno é um dicionário. Seria possível usar outras estruturas:

FormaExemploQuando usar
Dicionárioaluno["media"]O que o projeto usa: casa direto com o DictReader e o DictWriter, e as chaves têm nome
Lista ou tuplaaluno[3]Evite aqui: aluno[3] não diz nada a quem lê, e uma coluna nova bagunça as posições
Classe Alunoaluno.mediaQuando o aluno passa a ter comportamento (a média virando um @property, por exemplo). Veja as Dataclasses

Desafios extras

  • Reprovado: acrescente uma terceira situação, reprovado, para média abaixo de 5. Quem fica com a Gabi (5,33)?
  • Por turma: mostre a média de cada turma (A e B) e quantos aprovados cada uma teve. Um dicionário com a turma como chave ajuda (aula Percorrendo um Dicionário).
  • Vírgula decimal: faça o ler_alunos aceitar 5,5 e 5.5, e avisar (sem quebrar) quando uma nota estiver em branco.
  • O nome do arquivo na linha de comando: receba o nome do CSV em sys.argv (aula Os Módulos os e sys), para usar o mesmo programa com outras turmas.

Resumo

  • Versão 1: csv.DictReader lê cada linha como dicionário, com o cabeçalho como chaves. Tudo vem como texto.
  • Versão 2: float() na leitura, uma função para a média e outra para a situação (>= 7, aprovado).
  • Versão 3: sort(key=…, reverse=True) ordena pela média; :<, :^ e :> nas f-strings alinham as colunas.
