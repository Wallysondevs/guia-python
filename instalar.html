Python Instalar

As caixas Experimente do guia rodam Python de verdade no navegador, então você pode estudar as primeiras aulas sem instalar nada. Mas, para escrever os seus próprios programas, guardar os arquivos e rodar quando quiser, você vai querer o Python no seu computador. A boa notícia: no Linux ele quase sempre já vem instalado, e no Windows e no macOS a instalação leva poucos minutos. Nesta aula você vai conferir a sua versão, entender por que o comando python não existe no Ubuntu, instalar as peças que faltam e fazer um teste final.

Você vai aprender
  • Como descobrir se o Python já está instalado, e qual versão, com python3 --version.
  • Por que, no Ubuntu, o comando é python3, e o que acontece se você digitar só python.
  • Para que servem o python3-pip e o python3-venv, e como instalá-los.
  • Qual editor usar para escrever os programas.
  • Como instalar no Fedora e no Arch, no Windows (o novo Python install manager) e no macOS (python.org e Homebrew).
  • Os erros mais comuns de quem está instalando, com as mensagens reais.

As saídas de terminal desta aula vêm do computador da Ana, que usa Ubuntu 26.04. O que não deu para rodar lá (os comandos que instalam com sudo, e tudo o que é de Windows e de macOS) está marcado como ilustrativo, conferido na documentação oficial (docs.python.org/3/using).

A ideia: a música e o tocador

Um arquivo de música no celular não toca sozinho: você precisa de um aplicativo de música para tocá-lo. Com o Python é igual. O seu programa (o arquivo .py) é a música; o interpretador Python é o tocador. "Instalar o Python" é instalar o tocador. Depois disso, qualquer programa Python, seu ou de outra pessoa, pode ser "tocado" no seu computador.

Junto com o interpretador vem a biblioteca padrão: centenas de ferramentas prontas (para datas, contas, arquivos, sorteios…). E existem duas peças extras, que no Ubuntu vêm em pacotes separados:

PeçaO que éComparação
python3O interpretador e a biblioteca padrãoO tocador de música
pipO instalador de pacotes: bibliotecas feitas por outras pessoas, que não vêm com o PythonA loja onde você baixa músicas novas
venvCria um ambiente virtual: uma pasta separada, só de um projeto, com os pacotes deleUma playlist separada para cada ocasião, sem misturar tudo

Para as aulas do Nível 1, só o python3 basta. O pip e o venv têm aulas próprias, mais adiante (pip: Instalando Pacotes e Ambientes Virtuais (venv)), mas vale instalar logo, para não esquecer.

1. O Python já está instalado?

Antes de instalar, pergunte ao computador. Abra o terminal (no Ubuntu: Ctrl+Alt+T) e digite:

$ python3 --version
Python 3.14.4
python3
O nome do interpretador do Python 3, como você aprendeu na Introdução.
--version
"Versão": em vez de rodar um programa, mostre a versão e saia. O atalho -V (V maiúsculo) faz o mesmo.

A resposta Python 3.14.4 quer dizer: Python 3, versão 3.14, revisão 4 (as revisões só corrigem defeitos; tudo o que o guia ensina vale para qualquer 3.14.x). O atalho dá a mesma resposta:

$ python3 -V
Python 3.14.4

E onde ele está? O comando which ("qual") mostra o caminho do programa:

$ which python3
/usr/bin/python3
$ ls /usr/bin/python*
/usr/bin/python3
/usr/bin/python3.14                                « o mesmo Python, pelo nome completo

Se apareceu uma versão, o Python já está aí. Se ela for a 3.14 ou mais nova, você tem tudo de que o guia precisa. Se for mais antiga, veja a tabela da próxima seção.

2. Ubuntu e Debian: já vem instalado

O Ubuntu e o Debian usam o Python nos seus próprios programas (você viu um deles na Introdução: a mensagem de "comando não encontrado"). Por isso, o python3 vem em toda instalação. A versão depende da versão do sistema:

SistemaPython que vem com ele
Ubuntu 26.04 LTS (o da Ana)3.14
Ubuntu 24.04 LTS3.12
Debian 13 ("trixie")3.13
Debian 12 ("bookworm")3.11
Tenho um Python mais antigo. E agora?

Quase tudo do Nível 1 funciona igual do 3.10 em diante. O que é novidade da 3.14 vem marcado no guia com o selo 3.14, e a página Novidades do Python reúne essas mudanças. Duas diferenças você vai notar logo: as dicas nas mensagens de erro e as cores do modo interativo ficaram melhores nas versões novas. Não troque o Python do sistema por outro "na mão": o Ubuntu depende dele. Se precisar mesmo de uma versão mais nova, use as caixas Experimente do guia (que rodam o 3.14) ou atualize o sistema.

O comando python não existe

Muito tutorial na internet manda digitar python, sem o 3. No Ubuntu, a Ana tentou:

$ python --version
Comando 'python' não encontrado, você quis dizer:
  comando 'python3' do deb python3
  comando 'python' do deb python-is-python3

O terminal não achou nenhum programa chamado python, e o Ubuntu (com aquele programa escrito em Python) sugeriu duas saídas. A palavra "deb" quer dizer "pacote" (os pacotes do Ubuntu são arquivos .deb):

  • comando 'python3' do deb python3: "existe o comando python3, do pacote python3", que já está instalado. É só usar python3.
  • comando 'python' do deb python-is-python3: "existe um pacote chamado python-is-python3" ("python é python3"), que cria o comando python como um apelido do python3.

O apt deixa simular a instalação, sem instalar nada, com -s. Assim dá para ver o que ela faria:

$ apt-get install -s python-is-python3

Para instalar de verdade, o comando seria sudo apt install python-is-python3 (ilustrativo: o sudo pede a sua senha, e a Ana não instalou). Este guia não precisa dele: todas as aulas usam python3, que funciona em qualquer Ubuntu e Debian, sem instalar nada. Quando um tutorial disser python, escreva python3.

3. O pip e o venv

Numa instalação nova do Ubuntu, o python3 vem, mas o pip e o venv não. Eles estão nos pacotes python3-pip e python3-venv. Para instalar os dois de uma vez (ilustrativo; o sudo pede a sua senha):

sudo apt install python3-pip python3-venv
sudo
"Faça como administrador". Instalar programas mexe no sistema, então o Ubuntu pede a sua senha. Enquanto você digita, nada aparece na tela (nem asteriscos): é normal.
apt
O gerenciador de pacotes do Ubuntu e do Debian: a "loja de aplicativos" do terminal.
install
"Instale".
python3-pip python3-venv
Os dois pacotes, separados por espaço.

No computador da Ana, eles já estavam instalados. A simulação mostra isso:

Para conferir depois de instalar, pergunte a versão do pip. O jeito recomendado é pedir ao próprio Python que rode o módulo pip (-m quer dizer "módulo"):

$ python3 -m pip --version
pip 25.1.1 from /usr/lib/python3/dist-packages/pip (python 3.14)

A resposta diz a versão do pip (25.1.1), onde ele está e, no fim, para qual Python ele instala pacotes: o 3.14. Também dá para listar os pacotes do Python instalados no sistema:

$ apt list --installed 2>/dev/null | grep -E "^python3(-pip|-venv|\.14|-minimal)?/"
python3-minimal/resolute,now 3.14.3-0ubuntu2 amd64 [instalado,automático]
python3-pip/resolute,now 25.1.1+dfsg-1ubuntu2 all [instalado]
python3-venv/resolute,now 3.14.3-0ubuntu2 amd64 [instalado]

python3/resolute,now 3.14.3-0ubuntu2 amd64 [instalado]

(O grep filtrou a lista enorme, deixando só as linhas que interessam; o 2>/dev/null esconde um aviso do apt. Não se preocupe com esses detalhes do terminal.)

Tudo de uma vez: python3-full

O pacote python3-full é um "kit" que traz o Python completo: o venv, o editor IDLE e o tkinter (para janelas). Se você não quer pensar em pacotes, sudo apt install python3-full python3-pip resolve (ilustrativo). A lista do que vem no kit:

$ apt-cache show python3-full | grep -E "^(Depends|Description)"
Depends: python3 (= 3.14.3-0ubuntu2), python3.14-full (>= 3.14.3), python3-venv (= 3.14.3-0ubuntu2), idle, python3-gdbm, python3-tk
Description-en: Default Python Interpreter with complete class library
Não use sudo pip install

No Ubuntu e no Debian, o pip se recusa a instalar pacotes direto no Python do sistema (ele mostra um erro chamado externally-managed-environment). É de propósito: o sistema depende daquele Python, e um pacote errado pode quebrá-lo. O jeito certo é instalar pacotes dentro de um ambiente virtual. As aulas pip e venv mostram o passo a passo; até lá, você não vai precisar de pacote nenhum.

4. Um editor para escrever os programas

Um programa Python é um arquivo de texto puro. Qualquer editor de texto serve, menos os de "documento", como o LibreOffice Writer ou o Word: eles gravam fontes, cores e margens junto com o texto, e o Python não entende nada disso. Algumas opções:

EditorComo conseguir no UbuntuBom para
nanoJá vem. Roda dentro do terminal.Arquivos pequenos, sem sair do terminal. É o que as aulas usam (aula Rodando um Programa).
Editor de TextoJá vem (é o editor com janela do Ubuntu).Começar sem instalar nada.
Thonnysudo apt install thonny (ilustrativo)Iniciantes: um editor feito para aprender Python, com um botão de rodar e um modo que mostra o programa passo a passo.
IDLEsudo apt install idle (ilustrativo)O editor que vem com o Python no Windows e no macOS. Simples, com o modo interativo embutido.

Não existe editor "certo". Para as primeiras aulas, o nano ou o Thonny são ótimos. Se for usar o Editor de Texto, o VS Code ou outro, confira nas configurações que a tecla Tab insere 4 espaços (você vai entender o porquê na aula Sintaxe e Indentação).

6. Windows

O Windows não vem com Python. Desde a versão 3.14, o jeito recomendado pela documentação oficial é o Python install manager ("gerenciador de instalação do Python"): um programa pequeno que instala o Python, cria os comandos no terminal e cuida das atualizações. Tudo nesta seção é ilustrativo (o computador da Ana usa Linux), conferido em docs.python.org/3/using/windows.html.

Instalando o Python install manager

  1. Abra a Microsoft Store, procure por "Python install manager" (ou "Python") e clique em Instalar. Outra opção: baixe o instalador do Windows em python.org/downloads e dê dois cliques nele. A documentação diz que as duas versões são idênticas.
  2. Abra o Terminal (ou o PowerShell) e digite python. Se nenhum Python estiver instalado ainda, o gerenciador baixa e instala a versão mais recente sozinho e abre o modo interativo.
  3. Na primeira instalação, ele pode perguntar se você quer acrescentar uma pasta ao PATH (a lista de pastas onde o Windows procura comandos). É opcional: python e py funcionam de qualquer jeito.

Depois de instalado, você tem estes comandos:

python --version          # mostra a versão do Python padrão
python ola.py             # roda um programa
py list                   # lista os Pythons instalados
py install 3.14           # instala o Python 3.14
py -V:3.14 ola.py         # roda com uma versão específica
ComandoO que é
pythonO comando recomendado para rodar o Python no Windows. Lá ele existe, e é o Python 3 (no Ubuntu, use python3).
pyO mesmo, mais as ordens para gerenciar versões: py list, py install, py uninstall. Útil quando você tem mais de um Python.
python3Existe, mas só para pegar quem digita por costume do Linux; a documentação não recomenda usar no Windows.

O instalador tradicional (está saindo)

Muito tutorial mostra o instalador antigo do python.org, um .exe com a caixinha "Add python.exe to PATH" na primeira tela. Ele ainda existe para o 3.14, mas está obsoleto: a documentação avisa que ele não será mais produzido a partir do Python 3.16. Se usar esse instalador, marque a caixinha do PATH; sem ela, o comando python não funciona no terminal.

Linux no Windows: o WSL

Se você quer seguir o guia exatamente como ele é, com os mesmos comandos do Ubuntu, o Windows 10 e o 11 podem rodar um Ubuntu de verdade dentro deles, o WSL (Windows Subsystem for Linux). Com ele, tudo das seções 1 a 4 vale igual.

7. macOS

O macOS tem uma pegadinha: ele pode até ter um /usr/bin/python3, mas esse Python é da Apple, para as ferramentas de programação dela (o Xcode), costuma ser antigo e incompleto, e a documentação oficial pede que você nunca o modifique nem apague. Instale o seu, por um destes dois caminhos (ilustrativo, conferido em docs.python.org/3/using/mac.html):

Pelo python.org

  1. Baixe o instalador do macOS (um arquivo .pkg) em python.org/downloads. O mesmo arquivo serve para Macs com processador Apple (M1, M2…) e Intel.
  2. Dê dois cliques e siga as telas. Ele cria a pasta Python 3.14 em Aplicativos, com o editor IDLE.
  3. Nessa pasta, dê dois cliques em Install Certificates.command. Ele instala os certificados que o Python usa para acessar sites com https. Sem isso, programas que baixam coisas da internet dão erro.
  4. Abra o Terminal e confira com python3 --version. O instalador ajusta o terminal para que o python3 seja o novo, e não o da Apple.

Pelo Homebrew

Quem já usa o Homebrew, o gerenciador de pacotes mais usado no macOS, pode instalar pelo terminal:

brew install python@3.14
python3 --version

Nos dois casos, no macOS o comando é python3, como no Ubuntu. Tudo o que o guia mostra no terminal vale igual lá.

Quando dá errado

Comando 'python' não encontrado 
$ python --version
Comando 'python' não encontrado, você quis dizer:
  comando 'python3' do deb python3
  comando 'python' do deb python-is-python3

O que aconteceu: no Ubuntu e no Debian, o comando se chama python3; python, sozinho, não existe. O tutorial que você estava seguindo era de Windows, de outra distribuição ou antigo.

Como resolver: escreva python3. (Ou, se fizer muita questão do nome curto, instale o python-is-python3.)

Python3 com P maiúsculo 
$ Python3 --version
Comando 'Python3' não encontrado, você quis dizer:
  comando 'python3' do deb python3 (3.14.3-0ubuntu2)
  comando 'cython3' do deb cython3 (3.1.6+dfsg-1ubuntu2)
Experimente: apt install <deb name>

O que aconteceu: no Linux, maiúsculas e minúsculas são letras diferentes: Python3 e python3 são nomes diferentes, e só o segundo existe. O Ubuntu percebeu a semelhança e sugeriu o python3 (e, de brinde, o cython3, um programa de nome parecido que não tem nada a ver com o assunto).

Como resolver: tudo em minúsculas: python3. Isso vai valer para o Python também: lá dentro, Print e print são coisas diferentes (aula Sintaxe e Indentação).

Opção digitada errada: Unknown option 
$ python3 --vesion
Unknown option: --vesion
usage: python3 [option] ... [-c cmd | -m mod | file | -] [arg] ...
Try `python -h' for more information.

O que aconteceu: faltou o r de --version. "Opção desconhecida: --vesion". Depois, o Python mostra o jeito de usar (usage): python3, opções, e então um programa (-c com um texto, -m com um módulo, ou um arquivo). A última linha diz "tente python -h para mais informações" (o -h é de help, "ajuda"; no Ubuntu, digite python3 -h).

Como resolver: python3 --version, ou o atalho python3 -V.

Digitei python3 --version dentro do Python

A Ana abriu o modo interativo do Python (o >>>) e, lá dentro, quis conferir a versão:

$ python3
Python 3.14.4 (main, Aug 20 2026, 10:41:58) [GCC 15.2.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> python3 --version
Traceback (most recent call last):
  File "<python-input-0>", line 1, in <module>
    python3 --version
    ^^^^^^^
NameError: name 'python3' is not defined
>>> exit
$ python3 --version
Python 3.14.4

O que aconteceu: o >>> quer dizer que quem está ouvindo é o Python, e não o terminal. O Python tentou entender python3 --version como uma conta ("python3 menos menos version") e reclamou: NameError: name 'python3' is not defined, "o nome python3 não está definido". Para o Python, python3 não é nada. Repare que a primeira linha (a que começa com Python 3.14.4) já tinha dito a versão.

Como resolver: saia do Python com exit e digite o comando no terminal, onde aparece o $. A aula O Modo Interativo (>>>) mostra a diferença entre os dois com calma.

Windows: digitar python abre a Microsoft Store (ilustrativo)

O que aconteceu: o Windows tem "apelidos de execução" (app execution aliases): atalhos que fazem o comando python abrir a loja quando nenhum Python está instalado, ou quando o apelido está desligado.

Como resolver: instale o Python install manager pela loja. Se ele já estiver instalado e o problema continuar, a documentação oficial sugere abrir o menu Iniciar, procurar por "aliases de execução" (em inglês, Manage app execution aliases) e conferir que os apelidos do Python estão ligados (se já estiverem, desligue e ligue de novo).

Um erro de digitação no programa de teste

A Ana digitou o teste com pressa e esqueceu uma letra:

prnt("Python está funcionando!")

$ python3 teste_erro.py
Traceback (most recent call last):
  File "/home/ana/teste_erro.py", line 1, in <module>
    prnt("Python está funcionando!")
    ^^^^
NameError: name 'prnt' is not defined. Did you mean: 'print'?

O que aconteceu: a instalação está ótima; o erro é do programa. Traceback (most recent call last) é o "rastro" do erro ("a chamada mais recente por último"); depois vêm o arquivo e a linha, a linha copiada, os ^^^^ embaixo de prnt e a explicação: "o nome prnt não está definido. Você quis dizer print?". A aula Lendo uma Mensagem de Erro ensina a ler todo tipo de traceback.

Como resolver: conserte para print.

Missão: o programa de teste da Ana dá NameError. Rode para ver o erro, conserte e rode de novo, até aparecer Python está funcionando!.

prnt("Python está funcionando!")

print("Python está funcionando!")

Resumo

  • Instalar o Python é instalar o interpretador, o "tocador" dos seus programas .py. Confira se ele já está aí com python3 --version.
  • No Ubuntu e no Debian, o Python já vem (o Ubuntu 26.04 traz o 3.14). O comando é python3; python, sozinho, dá "Comando 'python' não encontrado".
  • O pip (instalador de pacotes) e o venv (ambientes virtuais) vêm em python3-pip e python3-venv: sudo apt install python3-pip python3-venv. Nunca use sudo pip install.
  • Escreva os programas num editor de texto puro (nano, Thonny, IDLE, VS Code), com Tab valendo 4 espaços.
  • No Windows, use o Python install manager (comandos python e py); o instalador .exe antigo está saindo e, se usado, precisa da caixinha do PATH.
  • No macOS, instale pelo python.org (e rode o Install Certificates.command) ou pelo Homebrew; o comando é python3.
  • Dentro do >>> quem ouve é o Python; os comandos do terminal vão no $.
  • Próximo passo: escrever um arquivo e rodá-lo, em Rodando um Programa (.py).
