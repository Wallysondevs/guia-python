Python Recursão

Você já sabe que uma função pode chamar outra: dentro de uma função, você usa print(), len() ou uma função sua. Mas uma função também pode chamar a si mesma. Isso se chama recursão (do latim recurrere, "voltar a correr"). Parece um truque estranho, e tem um perigo (a função que se chama para sempre), mas é um jeito elegante de resolver problemas que se repetem "em tamanho menor". Nesta aula você vai ver como ela funciona por dentro, quando usar e o que acontece quando dá errado.

Você vai aprender
  • O que é uma função recursiva e as suas duas partes: o caso base e o passo recursivo.
  • A fazer uma contagem regressiva sem laço nenhum.
  • A calcular o fatorial com return e a acompanhar, passo a passo, as chamadas que o Python faz.
  • A somar uma lista com recursão.
  • A comparar recursão com o laço for e a escolher o melhor para cada caso.
  • O erro real quando falta o caso base: RecursionError: maximum recursion depth exceeded.

A ideia: a fila do cinema

A Ana está numa fila enorme de cinema, no escuro, e quer saber em que lugar está. Ela não consegue contar as pessoas lá na frente. Então ela cutuca a pessoa da frente e pergunta: "em que lugar você está?". Essa pessoa também não sabe, e faz a mesma pergunta para a pessoa da frente dela. E assim por diante, até chegar na primeira pessoa da fila, que olha para a frente, não vê ninguém e responde: "eu sou a número 1".

Aí a resposta volta: a segunda pessoa diz "então eu sou a 2", a terceira diz "eu sou a 3"… até chegar na Ana.

Repare nas duas partes dessa história:

  • A pergunta repetida em tamanho menor: cada pessoa faz a mesma pergunta, para uma fila que tem uma pessoa a menos. Em programação, é o passo recursivo: a função chama a si mesma com um problema menor.
  • Alguém que sabe a resposta sem perguntar: a primeira da fila. É o caso base: o ponto em que a função para de se chamar e responde direto.

Sem a primeira pessoa da fila, a pergunta passaria de mão em mão para sempre. Guarde isso: toda função recursiva precisa de um caso base.

1. A primeira função recursiva: a contagem regressiva

Um foguete vai ser lançado. A contagem começa em 3 e, quando chega a zero, aparece "Fogo!". Com recursão:

def contagem(n):
    if n == 0:
        print("Fogo!")
    else:
        print(n)
        contagem(n - 1)


contagem(3)
def contagem(n):
Uma função comum, com um parâmetro n: o número de onde a contagem começa.
if n == 0:
O caso base: quando a contagem chega a zero, não há mais o que contar.
print("Fogo!")
O que fazer no caso base. Aqui a função termina, sem chamar a si mesma.
print(n)
Fora do caso base, mostra o número atual…
contagem(n - 1)
…e o passo recursivo: a função chama a si mesma com um número menor. Cada chamada chega um pouco mais perto do zero.
contagem(3)
A primeira chamada, feita de fora da função. É ela que põe tudo em movimento.
$ python3 contagem.py
3
2
1
Fogo!

Não há for nem while no programa, e mesmo assim os números se repetiram. O que aconteceu, chamada por chamada:

  1. contagem(3): 3 não é zero. Mostra 3 e chama contagem(2).
  2. contagem(2): mostra 2 e chama contagem(1).
  3. contagem(1): mostra 1 e chama contagem(0).
  4. contagem(0): é o caso base. Mostra Fogo! e não chama mais ninguém.
  5. A contagem(0) termina e volta para a contagem(1), que não tem mais nada para fazer e termina também; o mesmo com a 2 e a 3. O programa acaba.
Cada chamada tem o seu próprio n

Quando contagem(3) chama contagem(2), o n que vale 3 não muda: a nova chamada ganha um n novo, só dela, que vale 2. É como as pessoas da fila: cada uma tem a sua resposta. Você viu isso na aula Escopo: as variáveis de dentro de uma função são locais, e cada chamada tem as suas.

2. Recursão com return: o fatorial

O fatorial de um número, escrito 5! na matemática, é a multiplicação dele por todos os números inteiros menores, até o 1:

5! = 5 × 4 × 3 × 2 × 1 = 120

Ele aparece quando você quer saber de quantos jeitos dá para arrumar coisas em fila: 5 livros numa prateleira podem ficar em 120 ordens diferentes. Agora repare num detalhe: 4 × 3 × 2 × 1 é o 4!. Então:

5! = 5 × 4!, e 4! = 4 × 3!, e assim por diante, até 1! = 1.

É o mesmo problema "em tamanho menor", como a fila do cinema. Em Python, fica quase igual à matemática:

def fatorial(n):
    if n == 1:
        return 1
    return n * fatorial(n - 1)


print(fatorial(5))
print(fatorial(1))
print(fatorial(10))
if n == 1:
O caso base: o fatorial de 1 é 1, sem conta nenhuma.
return 1
Devolve a resposta direto (veja a aula return). O return também termina a função, por isso não precisa de else.
return n * fatorial(n - 1)
O passo recursivo: "o fatorial de n é n vezes o fatorial de n - 1". Para fazer a multiplicação, o Python precisa primeiro descobrir quanto vale fatorial(n - 1), e para isso chama a função de novo.
$ python3 fatorial.py
120
1
3628800

Acompanhando as chamadas

Na contagem, cada chamada fazia o seu trabalho antes de chamar a próxima. No fatorial é diferente: cada chamada fica esperando a resposta da próxima para poder multiplicar. Para enxergar isso, esta versão mostra uma mensagem quando cada chamada começa e quando devolve a resposta. O parâmetro extra nivel só serve para empurrar o texto para a direita a cada chamada (4 espaços por nível):

def fatorial(n, nivel=0):
    recuo = "    " * nivel
    print(f"{recuo}fatorial({n}) começou")
    if n == 1:
        print(f"{recuo}fatorial(1) devolve 1")
        return 1
    resultado = n * fatorial(n - 1, nivel + 1)
    print(f"{recuo}fatorial({n}) devolve {resultado}")
    return resultado


print("Resposta:", fatorial(4))

A pilha de chamadas

Enquanto uma chamada espera a próxima, o Python guarda o lugar dela (onde parou e quanto valem as suas variáveis), como pratos numa pilha: cada chamada nova vai para o topo, e só depois que ela termina o Python volta para a de baixo. Essa pilha se chama pilha de chamadas (em inglês, call stack). Ela tem um tamanho máximo, e é isso que você vai ver estourar em Quando dá errado.

3. Somando uma lista com recursão

A recursão não serve só para números. A Ana anotou os preços da feira numa lista e quer o total. Pense assim: o total da lista é o primeiro preço mais o total do resto. E o total de uma lista vazia é zero (o caso base).

def somar(precos):
    if not precos:
        return 0
    return precos[0] + somar(precos[1:])


compras = [12.5, 8.0, 4.25, 30.0]
print(somar(compras))
print(somar([]))
if not precos:
O caso base. Uma lista vazia vale False numa condição (veja a aula Booleanos), então not precos é verdade quando a lista está vazia.
return 0
A soma de nenhum preço é zero.
precos[0]
O primeiro preço da lista (aula Acessando Itens).
precos[1:]
Uma fatia com todos menos o primeiro: uma lista um item menor. É o "problema em tamanho menor".
somar(precos[1:])
O passo recursivo: a soma do resto.
$ python3 soma_lista.py
54.75
0

As chamadas foram: somar([12.5, 8.0, 4.25, 30.0]) → somar([8.0, 4.25, 30.0]) → somar([4.25, 30.0]) → somar([30.0]) → somar([]), que devolve 0. Na volta: 30.0 + 0, 4.25 + 30.0, 8.0 + 34.25 e 12.5 + 42.25 = 54.75.

Como pensar uma função recursiva

Faça sempre as mesmas duas perguntas:

  1. Qual é o caso mais simples, que eu sei responder sem conta nenhuma? (zero, 1, a lista vazia, o texto vazio.) Esse é o caso base.
  2. Se alguém me der a resposta do problema um pouco menor, como eu chego na resposta do problema inteiro? Esse é o passo recursivo.

E confira: cada chamada tem de chegar mais perto do caso base (n - 1, precos[1:]). Se não chegar, a função nunca para.

Formas diferentes de fazer a mesma coisa

Tudo o que se faz com recursão também se faz com um laço. O fatorial de 5, de três jeitos:

1. Com recursão, como você viu acima (fatorial.py).

2. Com um laço for (aulas for e range()): começa em 1 e vai multiplicando por 2, 3, 4 e 5.

def fatorial(n):
    resultado = 1
    for numero in range(2, n + 1):
        resultado = resultado * numero
    return resultado


print(fatorial(5))

FormaQuando usar
RecursãoQuando o problema é naturalmente "ele mesmo, em tamanho menor": pastas dentro de pastas, uma árvore genealógica, um menu com submenus, dicionários dentro de dicionários. Aí a versão recursiva costuma ser a mais curta e a mais fácil de ler
Laço (for / while)Na maioria dos casos do dia a dia, como somar, contar e repetir. Não tem limite de profundidade e é o que os programadores Python esperam ler
Função pronta (math.factorial, sum)Sempre que existir. Já está testada e é mais rápida. Para somar uma lista, use sum(compras) (aula Funções Embutidas)
Por que aprender recursão, então?

Porque há problemas em que o laço fica complicado e a recursão fica simples: percorrer uma pasta que tem subpastas, que têm outras subpastas, sem saber quantos níveis existem. E porque você vai encontrá-la no código dos outros. Os exemplos desta aula (contagem, fatorial, soma) são simples de propósito, para você ver o mecanismo; no dia a dia, para eles, prefira o laço ou a função pronta.

Qual é o limite?

O Python limita quantas chamadas podem ficar empilhadas, para que uma recursão sem fim termine num erro claro em vez de travar o computador. No Python 3.14 do Ubuntu da Ana, o limite é 1000, e dá para consultá-lo:

$ python3 -c "import sys; print(sys.getrecursionlimit())"
1000

O <module> (o corpo do programa) conta como uma das mil; por isso couberam 999 chamadas da contagem. Os números do traceback podem variar de um lugar para outro. No editor do guia, que roda o Python dentro do navegador, o sys.getrecursionlimit() também responde 1000 e cabem as mesmas chamadas: a contagem também vai até o -995, e o traceback diz o mesmo [Previous line repeated 996 more times]. Em outros computadores e versões, o limite pode ser outro. Não decore o número; lembre que existe um limite. Existe também a função sys.setrecursionlimit(), que muda esse limite, mas ela não conserta uma função sem caso base: só faz o erro demorar mais para aparecer.

def fatorial(n):
    if n <= 1:
        return 1
    return n * fatorial(n - 1)

Com n <= 1 (menor ou igual a 1), tanto o 1 quanto o 0 param a recursão. (Para números negativos, que não têm fatorial, o certo seria avisar com um erro; a aula raise mostra como.)

Resumo

  • Uma função recursiva chama a si mesma, sempre com um problema menor.
  • Ela tem duas partes: o caso base (responde direto e para) e o passo recursivo (chama a si mesma com um problema menor).
  • Cada chamada tem as suas próprias variáveis. As chamadas "descem" até o caso base e as respostas "sobem" de volta.
  • Sem caso base, ou com um caso base fora do caminho, a função não para: RecursionError: maximum recursion depth exceeded, com [Previous line repeated … more times] no traceback.
  • O Python limita a pilha de chamadas (1000 no Ubuntu da Ana e no editor do guia; pode ser outro em outro lugar).
  • Tudo o que se faz com recursão se faz com laço. Use recursão quando o problema é "ele mesmo em tamanho menor" (pastas dentro de pastas); no resto, laço ou função pronta.
