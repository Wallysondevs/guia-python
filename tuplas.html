Python Tuplas

Você já conhece as listas: uma fila de valores que pode crescer, encolher e mudar. Só que alguns grupos de valores nunca deveriam mudar: os sete dias da semana, os meses do ano, a data em que a Ana nasceu, a localização da padaria no mapa. Para esses casos o Python tem a tupla (em inglês, tuple): uma sequência de valores, na ordem, que depois de criada não muda mais.

Você vai aprender
  • A criar uma tupla com parênteses e vírgulas, e a reconhecer uma pelo type().
  • A ler os itens com índices, fatias, len(), in e for, igual às listas.
  • O detalhe que pega todo mundo: a tupla de um item só precisa de vírgula, (5,).
  • Por que a tupla não muda, e as mensagens reais do Python quando você tenta mudar.
  • Os dois métodos da tupla, count() e index().
  • A converter tupla em lista e lista em tupla, e quando usar cada uma.

A ideia: uma lista escrita a caneta

Pense na lista de compras da Ana, escrita a lápis: ela apaga um item, acrescenta outro, troca a ordem. Isso é uma lista do Python. Agora pense no calendário pendurado na cozinha, impresso: os dias da semana estão lá, sempre os mesmos sete, sempre na mesma ordem. Ninguém apaga a "quarta-feira". Isso é uma tupla.

As duas guardam vários valores em ordem e você lê os itens do mesmo jeito. A diferença é só uma: a lista pode ser alterada, a tupla não. Em Python se diz que a lista é mutável (pode mudar) e a tupla é imutável (não pode mudar).

2. Lendo os itens: igual à lista

Tudo o que serve para ler uma lista serve para ler uma tupla: índice começando do zero, índice negativo contando do fim, fatias, in e o laço for.

dias = ("seg", "ter", "qua", "qui", "sex", "sáb", "dom")
print(dias[0])
print(dias[-1])
print(dias[1:5])
print("sáb" in dias)
for dia in dias:
    print("Hoje é", dia)

3. Tuplas guardam coisas que andam juntas

O uso mais comum da tupla não é guardar uma fila comprida de coisas iguais, e sim juntar poucos valores que formam uma coisa só: a latitude e a longitude de um lugar, o dia, o mês e o ano de uma data.

padaria = (-5.0892, -42.8019)
print("Latitude:", padaria[0])
print("Longitude:", padaria[1])
aniversario = (12, 3, 1990)
print(f"Nasci em {aniversario[0]}/{aniversario[1]}/{aniversario[2]}")

$ python3 coordenada.py
Latitude: -5.0892
Longitude: -42.8019
Nasci em 12/3/1990

Uma coordenada sempre tem dois números; uma data, três. Não faz sentido "acrescentar um item" a uma data. A tupla deixa isso claro para quem lê o código: esses valores andam juntos e ficam como estão. Na próxima aula, Desempacotamento, você vai ver um jeito mais bonito de tirar cada valor da tupla em vez de usar [0], [1], [2].

4. A tupla de um item só: a vírgula é que manda

Aqui está a pegadinha mais famosa das tuplas. Quem faz a tupla não são os parênteses, é a vírgula. Os parênteses também servem para outra coisa em Python: agrupar contas, como em (2 + 3) * 4. Então, quando há um item só, o Python precisa de uma pista para saber que você quer uma tupla.

sem_virgula = ("arroz")
com_virgula = ("arroz",)
print(sem_virgula, type(sem_virgula))
print(com_virgula, type(com_virgula))
numero = (5)
tupla = (5,)
print(numero, type(numero))
print(tupla, type(tupla))

$ python3 um_item.py
arroz <class 'str'>
('arroz',) <class 'tuple'>
5 <class 'int'>
(5,) <class 'tuple'>
("arroz")
Parênteses em volta de um texto, só isso. O Python trata como se fosse "arroz" sozinho: o tipo é str (texto).
("arroz",)
Com a vírgula depois do item, agora sim é uma tupla de um item. O próprio Python, ao mostrar, escreve a vírgula: ('arroz',).
(5)
É só o número 5 entre parênteses, como numa conta: tipo int.
(5,)
Uma tupla com um item, o número 5.

5. Sem parênteses e vazia

Como é a vírgula que faz a tupla, você pode criar uma sem parênteses nenhum. E para uma tupla vazia, sem itens, há duas formas: () ou tuple().

ponto = 3, 4
print(ponto)
print(type(ponto))
um = "café",
print(um)
vazia = ()
tambem_vazia = tuple()
print(vazia, len(vazia))
print(tambem_vazia, len(tambem_vazia))

$ python3 sem_parenteses.py
(3, 4)
<class 'tuple'>
('café',)
() 0
() 0
Boa prática: use os parênteses

Funcionar sem parênteses funciona, mas um = "café", é fácil de não ver: aquela vírgula no fim parece um erro de digitação. Escreva um = ("café",): quem ler o seu código entende na hora que é uma tupla. Sem parênteses, a tupla aparece mais em return a, b e na troca a, b = b, a, que você vai ver em Desempacotamento.

6. A tupla não muda

Agora a característica principal. A Ana resolve escrever o nome completo do primeiro dia e tenta trocar o item, como faria numa lista:

dias = ("seg", "ter", "qua", "qui", "sex", "sáb", "dom")
dias[0] = "segunda"
print(dias)

$ python3 mudar.py
Traceback (most recent call last):
  File "/home/ana/mudar.py", line 2, in <module>
    dias[0] = "segunda"
    ~~~~^^^
TypeError: 'tuple' object does not support item assignment

É a primeira vez que este erro aparece no guia; vamos ler linha por linha:

Traceback (most recent call last):
"Rastro (a chamada mais recente por último)". O Python avisa que deu erro e vai mostrar onde.
File "/home/ana/mudar.py", line 2, in <module>
O erro está no arquivo mudar.py, na linha 2, no corpo principal do programa (<module>).
dias[0] = "segunda"
A linha que deu problema.
~~~~^^^
Os tils e acentos circunflexos apontam o pedaço exato: dias[0], o lugar onde você tentou guardar um valor.
TypeError: 'tuple' object does not support item assignment
"Erro de tipo: um objeto do tipo tupla não aceita atribuição de item". Em português claro: você não pode trocar um item de uma tupla. O print da linha 3 nem chegou a rodar: o programa parou no erro.

Pela mesma razão, a tupla não tem append(), remove(), sort() nem nenhum outro método que mude a lista no lugar. Se você tentar:

dias = ("seg", "ter", "qua")
dias.append("qui")

$ python3 append.py
Traceback (most recent call last):
  File "/home/ana/append.py", line 2, in <module>
    dias.append("qui")
    ^^^^^^^^^^^
AttributeError: 'tuple' object has no attribute 'append'

AttributeError quer dizer "erro de atributo": a tupla não tem nada chamado append. Não é que o append falhou; ele nem existe para tuplas.

Então para que serve algo que não muda?

  • Segurança: se um valor não deveria mudar (os dias da semana, uma data), guardá-lo numa tupla impede que um pedaço do programa o altere por engano. Se alguém tentar, o Python reclama na hora, em vez de deixar o erro escondido.
  • Clareza: quem lê (12, 3, 1990) entende que é um registro fixo, não uma fila que vai crescer.
  • Chave de dicionário: só valores que não mudam podem ser chave de um dicionário. Uma tupla pode; uma lista não. Você vai ver isso em Dicionários.
A variável pode mudar, a tupla não

A tupla não muda, mas a variável pode passar a guardar outra tupla: dias = ("segunda", "terça") funciona. Você não alterou a tupla antiga; jogou ela fora e colocou uma nova no lugar. A diferença entre mudar o valor e trocar o valor da variável é o assunto da aula Mutável × Imutável.

7. Os dois métodos da tupla: count() e index()

Como a tupla não muda, sobram só dois métodos, os dois de consulta. E as funções que só leem (min, max, sum, sorted) funcionam normalmente.

notas = (7, 9, 7, 10, 7, 8)
print(notas.count(7))
print(notas.index(10))
print(notas.index(7))
print(min(notas), max(notas), sum(notas))
print(sorted(notas))

Devolve os itens em ordem, mas numa lista nova (repare nos colchetes). A tupla notas continua como estava.

8. Convertendo: tupla ⇄ lista

E se você realmente precisar mudar? Converta a tupla em lista com list(), mude a lista, e converta de volta com tuple():

cores = ("vermelho", "verde", "azul")
lista = list(cores)
lista.append("amarelo")
cores = tuple(lista)
print(cores)

$ python3 converter.py
('vermelho', 'verde', 'azul', 'amarelo')
  1. list(cores) cria uma lista nova com os mesmos itens da tupla.
  2. A lista aceita append: agora ela tem quatro cores.
  3. tuple(lista) cria uma tupla nova com os itens da lista, e a variável cores passa a guardá-la.

Outro jeito de "aumentar" uma tupla é juntar duas com +. O resultado é uma tupla nova; as originais ficam como estavam. O * repete:

manha = ("café", "pão")
tarde = ("bolo",)
lanches = manha + tarde
print(lanches)
print(manha)
print(("oi",) * 3)

$ python3 juntar.py
('café', 'pão', 'bolo')
('café', 'pão')
('oi', 'oi', 'oi')

Quando dá errado

Trocar um item da tupla

Já visto acima: dias[0] = "segunda" dá TypeError: 'tuple' object does not support item assignment. Como consertar: se os itens precisam mudar, use uma lista desde o começo. Se a mudança é rara, converta com list(), mude e volte com tuple().

Resumo

  • A tupla é uma sequência em ordem, escrita com parênteses: ("seg", "ter"). O tipo dela é tuple.
  • Lê-se igual à lista: t[0], t[-1], fatias, len, in, for.
  • Quem faz a tupla é a vírgula: (5) é o número 5; (5,) é uma tupla.
  • A tupla é imutável: trocar um item dá TypeError, e não existem append, remove nem sort.
  • Os únicos métodos são count() e index().
  • Para mudar, converta: list(t), mude, tuple(lista). Ou junte com +, que cria uma tupla nova.
  • Use tupla para valores fixos ou que formam uma coisa só (data, coordenada); use lista para o que vai mudar.
