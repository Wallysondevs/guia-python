Python Métodos de Lista

Esta é a página de consulta rápida dos métodos de lista: as funções que toda lista (list) já traz e que você chama com um ponto, como em compras.append("café"). São só 11, para adicionar, remover, procurar, ordenar e copiar. No fim estão também as operações com listas que não são métodos (len, in, +, índices, fatias, del). A explicação passo a passo começa na aula Listas.

Como ler as tabelas
  • Exemplo é o que você digitaria depois do >>> do modo interativo, uma linha depois da outra; Resultado é o que o Python 3.14.4 respondeu no computador da Ana.
  • Muitos métodos de lista não devolvem nada (devolvem None, que o modo interativo não mostra): eles mudam a própria lista. Por isso vários exemplos terminam com o nome da lista sozinho, para mostrar como ela ficou.
  • Quando o exemplo dá erro, o resultado mostra a última linha da mensagem do Python (em inglês).
A diferença para as strings: a lista muda

Os métodos de string devolvem um texto novo e deixam o original igual. Os de lista fazem o contrário: mudam a própria lista e devolvem None ("nada"). Por isso nunca escreva compras = compras.sort():

$ python3 -q
>>> compras = ["pão", "leite", "café"]
>>> compras = compras.sort()
>>> print(compras)
None
>>> compras[0]
Traceback (most recent call last):
  File "<python-input-3>", line 1, in <module>
    compras[0]
    ~~~~~~~^^^
TypeError: 'NoneType' object is not subscriptable
>>> exit()

O sort() ordenou a lista e devolveu None, e a atribuição guardou esse None em compras: a lista se perdeu. A última linha, TypeError: 'NoneType' object is not subscriptable, quer dizer "o valor None não aceita [ ]". O certo é só compras.sort(), sem o compras =. O mesmo vale para append, extend, insert, remove, clear e reverse.

Qual usar para remover?
  • Sabe o valor ("leite"): remove.
  • Sabe a posição e quer o item de volta: pop(i). O pop() sem número é o jeito de usar uma lista como pilha (o último que entra é o primeiro que sai).
  • Sabe a posição e não precisa do item: del lista[i].
  • Quer tirar todos os itens de um valor: uma list comprehension, como [x for x in compras if x != "leite"].

Cópia rasa

copy(), [:] e list() copiam só a lista de fora. Se dentro dela houver outras listas, elas continuam compartilhadas. Para copiar tudo, até o fundo, existe o copy.deepcopy(): veja Cópia Rasa e Cópia Profunda.

Resumo

  • Os 11 métodos de lista: append, extend, insert, remove, pop, clear, index, count, sort, reverse, copy.
  • Quase todos mudam a própria lista e devolvem None: nunca escreva lista = lista.sort(). Só pop, index, count e copy devolvem algo útil.
  • append põe um item; extend põe vários; insert põe numa posição.
  • remove tira pelo valor; pop tira pela posição e devolve; del apaga pela posição.
  • sort() muda a lista; sorted() devolve uma nova. Os dois aceitam key= e reverse=True.
  • b = a não copia: use a.copy().
