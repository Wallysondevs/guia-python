Projeto: Agenda de Contatos (JSON)

A Ana quer parar de anotar telefones no caderno. Neste projeto você vai construir com ela uma agenda de contatos no terminal: listar, adicionar, buscar e remover contatos. E, o mais importante, lembrar de tudo: quando o programa fecha e abre de novo, os contatos continuam lá, guardados num arquivo contatos.json. É o primeiro programa do guia que guarda dados de verdade entre uma execução e outra.

Você vai praticar
  • Guardar cada contato num dicionário e todos eles numa lista; percorrer com for e enumerate().
  • Montar um menu com while, input(), if / elif / else e break.
  • Alinhar as colunas com f-strings e limpar o que foi digitado com strip() e lower().
  • Organizar o programa em funções com return.
  • Salvar e carregar com JSON, open e with e pathlib.
  • Tratar os erros com try e except: número inválido, arquivo que não existe, arquivo estragado.

O que vamos construir

A agenda pronta, no terminal da Ana. O que vem depois de cada Opção:, Nome:, Telefone: e Buscar: foi digitado por ela:

Quatro versões, uma novidade em cada:

  1. Os contatos na memória (uma lista de dicionários).
  2. O menu (while, input, break).
  3. Salvar e carregar (json.dump, json.load, ensure_ascii=False).
  4. Buscar, remover e tratar os erros (funções, try/except).

Versão 1 · Os contatos na memória

Antes de qualquer menu, a pergunta mais importante: como guardar um contato? Um contato tem várias informações (nome, telefone), cada uma com um nome. É exatamente o que um dicionário faz: {"nome": "Ana Souza", "telefone": "86 99999-0000"}. E vários contatos, em ordem, cabem numa lista. Uma lista de dicionários é como um fichário: a lista é a caixa, cada dicionário é uma ficha.

contatos = [
    {"nome": "Ana Souza", "telefone": "86 99999-0000"},
    {"nome": "Bia Lima", "telefone": "86 98888-7777"},
    {"nome": "Caio Rocha", "telefone": "11 97777-6666"},
]

print("=== Agenda ===")
for contato in contatos:
    print(f"{contato['nome']:<15} {contato['telefone']}")
print(f"{len(contatos)} contato(s)")
contatos = [ … ]
A lista, com um contato por linha. A vírgula depois do último item é permitida, e é o costume: assim, para acrescentar uma linha, você não precisa mexer na de cima.
{"nome": …, "telefone": …}
Um dicionário: cada chave ("nome", "telefone") tem o seu valor. O telefone é texto, e não número: tem espaço e traço, e ninguém faz conta com ele.
for contato in contatos:
Passa por cada ficha da lista; a cada volta, contato é um dicionário.
contato['nome']
Pega o valor da chave "nome". Dentro da f-string de aspas duplas, a chave foi escrita com aspas simples (veja a aula f-strings).
:<15
Ocupa 15 caracteres, encostado à esquerda: os telefones ficam alinhados numa coluna.
len(contatos)
Quantos itens a lista tem: quantos contatos.
$ python3 agenda.py
=== Agenda ===
Ana Souza       86 99999-0000
Bia Lima        86 98888-7777
Caio Rocha      11 97777-6666
3 contato(s)

Versão 2 · O menu

Ninguém quer editar o programa para acrescentar um contato. A versão 2 começa com a agenda vazia e pergunta o que fazer, de novo e de novo, até a Ana escolher sair. É o mesmo esquema de menu da Calculadora: um while True que só termina com break.

contatos = []

print("=== Agenda ===")
while True:
    print()
    print("1 - Listar   2 - Adicionar   0 - Sair")
    opcao = input("Opção: ").strip()

    if opcao == "1":
        if not contatos:
            print("A agenda está vazia.")
        for contato in contatos:
            print(f"{contato['nome']:<15} {contato['telefone']}")
    elif opcao == "2":
        nome = input("Nome: ").strip()
        telefone = input("Telefone: ").strip()
        contatos.append({"nome": nome, "telefone": telefone})
        print(f"{nome} entrou na agenda.")
    elif opcao == "0":
        print("Até logo!")
        break
    else:
        print("Opção inválida.")

  File "/home/ana/projetos/agenda/agenda.py", line 7, in <module>

O 1 foi lido na primeira volta. Na segunda, o input() encontrou o fim da entrada: EOFError: EOF when reading a line, "fim do arquivo (end of file) ao ler uma linha". Versão 3 · Salvar e carregar (contatos.json)

Para a agenda lembrar dos contatos, o programa precisa fazer duas coisas: ao começar, ler os contatos do arquivo; a cada contato novo, gravar a lista inteira no arquivo. O formato do arquivo é o JSON (aula JSON): um texto que se parece muito com listas e dicionários do Python, e que o módulo json converte nos dois sentidos.

import json
from pathlib import Path

ARQUIVO = Path("contatos.json")


def carregar():
    if not ARQUIVO.exists():
        return []
    with open(ARQUIVO, encoding="utf-8") as arquivo:
        return json.load(arquivo)


def salvar(contatos):
    with open(ARQUIVO, "w", encoding="utf-8") as arquivo:
        json.dump(contatos, arquivo, ensure_ascii=False, indent=2)


contatos = carregar()
print("=== Agenda ===")
print(f"{len(contatos)} contato(s) carregado(s) de {ARQUIVO}")

while True:
    print()
    print("1 - Listar   2 - Adicionar   0 - Sair")
    opcao = input("Opção: ").strip()

    if opcao == "1":
        if not contatos:
            print("A agenda está vazia.")
        for contato in contatos:
            print(f"{contato['nome']:<15} {contato['telefone']}")
    elif opcao == "2":
        nome = input("Nome: ").strip()
        telefone = input("Telefone: ").strip()
        contatos.append({"nome": nome, "telefone": telefone})
        salvar(contatos)
        print(f"{nome} entrou na agenda (salvo em {ARQUIVO}).")
    elif opcao == "0":
        print("Até logo!")
        break
    else:
        print("Opção inválida.")

Abre o arquivo para ler, com a codificação UTF-8 (a que guarda acentos), e fecha sozinho no fim do bloco (aula Abrindo Arquivos).
json.load(arquivo)
Lê o texto JSON do arquivo e devolve o valor Python: aqui, uma lista de dicionários.
open(ARQUIVO, "w", …)
O "w" (de write) abre para escrever, apagando o que havia. Tudo bem: a lista inteira vai ser gravada de novo.
json.dump(contatos, arquivo, …)
Faz o contrário do load: transforma a lista em texto JSON e grava no arquivo.

Grava os acentos como eles são: João, e não João. Veja o porquê logo abaixo.
indent=2
Quebra as linhas e recua 2 espaços por nível: o arquivo fica legível para gente.
salvar(contatos)
Logo depois de cada append: o arquivo está sempre em dia, mesmo que o programa feche de repente.

Por que ensure_ascii=False?

Sem essa opção, o json troca toda letra que não é do inglês (o ASCII) por um código \u, aquele da aula Caracteres de Escape. No modo interativo:

$ python3
Python 3.14.4 (main, Aug 20 2026, 10:41:58) [GCC 15.2.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> import json
>>> json.dumps({"nome": "João"})
'{"nome": "Jo\\u00e3o"}'
>>> json.dumps({"nome": "João"}, ensure_ascii=False)
'{"nome": "João"}'
>>> exit()

(O json.dumps, com s de string, devolve o JSON como texto em vez de gravar num arquivo. A barra aparece dobrada porque o modo interativo mostra o texto "como seria escrito no código".) Num arquivo gravado sem a opção, o João fica assim:

$ cat teste.json; echo
[
  {
    "nome": "João Conceição",
    "telefone": "86 98888-7777"
  }
]

Não é um erro: o json.load lê João de volta como João, e o programa funciona igual. Mas o arquivo fica ilegível para quem abre num editor de texto, e uma agenda brasileira tem acento em todo canto. Com ensure_ascii=False (e o encoding="utf-8" no open), o arquivo guarda João Conceição, como se escreve.

Versão 4 · Buscar, remover e tratar os erros

A última versão acrescenta as opções Buscar e Remover, e cuida dos erros que podem acontecer com quem usa o programa: digitar uma letra onde se espera um número, escolher um número que não existe, deixar o nome em branco, o arquivo estragado da versão 3. Como o programa cresceu, cada opção do menu virou uma função: o while lá embaixo ficou curto, e cada pedaço pode ser lido sozinho.

import json
import sys
from pathlib import Path

ARQUIVO = Path("contatos.json")


def carregar():
    try:
        with open(ARQUIVO, encoding="utf-8") as arquivo:
            return json.load(arquivo)
    except FileNotFoundError:
        return []
    except json.JSONDecodeError as erro:
        print(f"O arquivo {ARQUIVO} está com defeito: {erro}")
        print("Conserte o arquivo (ou renomeie) e rode de novo.")
        sys.exit(1)


def salvar(contatos):
    with open(ARQUIVO, "w", encoding="utf-8") as arquivo:
        json.dump(contatos, arquivo, ensure_ascii=False, indent=2)


def listar(contatos):
    if not contatos:
        print("A agenda está vazia.")
    for numero, contato in enumerate(contatos, start=1):
        print(f"{numero}. {contato['nome']:<15} {contato['telefone']}")


def adicionar(contatos):
    nome = input("Nome: ").strip()
    telefone = input("Telefone: ").strip()
    if not nome:
        print("O nome não pode ficar em branco.")
        return
    contatos.append({"nome": nome, "telefone": telefone})
    salvar(contatos)
    print(f"{nome} entrou na agenda.")


def buscar(contatos):
    termo = input("Buscar: ").strip().lower()
    achados = [c for c in contatos if termo in c["nome"].lower()]
    if not achados:
        print("Ninguém encontrado.")
    for contato in achados:
        print(f"{contato['nome']:<15} {contato['telefone']}")


def remover(contatos):
    listar(contatos)
    try:
        numero = int(input("Número do contato a remover: "))
    except ValueError:
        print("Digite o número que aparece na lista.")
        return
    if not 1 <= numero <= len(contatos):
        print("Não existe contato com esse número.")
        return
    contato = contatos.pop(numero - 1)
    salvar(contatos)
    print(f"{contato['nome']} saiu da agenda.")


contatos = carregar()
print("=== Agenda ===")
print(f"{len(contatos)} contato(s) carregado(s) de {ARQUIVO}")

while True:
    print()
    print("1 - Listar  2 - Adicionar  3 - Buscar  4 - Remover  0 - Sair")
    opcao = input("Opção: ").strip()

    if opcao == "1":
        listar(contatos)
    elif opcao == "2":
        adicionar(contatos)
    elif opcao == "3":
        buscar(contatos)
    elif opcao == "4":
        remover(contatos)
    elif opcao == "0":
        print("Até logo!")
        break
    else:
        print("Opção inválida.")

As novidades, função por função:

carregar(): try … except FileNotFoundError
Em vez de perguntar antes se o arquivo existe, o programa tenta abrir; se não existe, o open dá FileNotFoundError ("arquivo não encontrado"), e o except devolve a lista vazia (aula try e except).
except json.JSONDecodeError as erro:
O arquivo estragado da versão 3. O as erro guarda o erro numa variável, e o print mostra a explicação dele (Expecting ',' delimiter…) numa frase só, sem traceback.
sys.exit(1)
Encerra o programa com o código de saída 1, o sinal de "deu problema" (aula os e sys). Por que não começar com a agenda vazia? Porque, no primeiro contato novo, o salvar gravaria a lista vazia por cima do arquivo, e os contatos estragados, que ainda dá para consertar, se perderiam de vez.
enumerate(contatos, start=1)
Dá o número de cada contato junto com ele, começando do 1 (aula enumerate() e zip()). É o número que a Ana digita para remover.
adicionar(): if not nome: … return
Um texto vazio conta como falso: se o nome ficou em branco, avisa e o return sai da função sem adicionar nada (aula return).
termo in c["nome"].lower()
A busca: o in procura o pedaço em qualquer lugar do nome (aula is e in), com os dois lados em minúsculas. "jo" acha João; "bia" acha Bia Lima.
[c for c in contatos if …]
Uma list comprehension: a lista dos contatos que passam no teste.
remover(): int(input(…))
Aqui sim é preciso um número, para achar a posição na lista. Se a Ana digitar abc, o int() dá ValueError, e o except transforma isso num aviso.
if not 1 <= numero <= len(contatos):
Confere se o número está entre 1 e a quantidade de contatos, com uma comparação encadeada. A seção "Quando dá errado" mostra por que isso é indispensável.
contatos.pop(numero - 1)
Tira o contato da lista e devolve quem saiu (aula Removendo Itens). O - 1 é porque a Ana conta a partir do 1, e os índices começam no 0.

Por que conferir 1 <= numero <= len(contatos), se o pop de uma posição que não existe já dá erro (IndexError)? Por causa do zero. Veja o que pop(0 - 1) faz:

Formas diferentes de fazer a mesma coisa

TarefaOpçõesQual usar
Começar sem arquivoif not ARQUIVO.exists(): return [] (versão 3) · try … except FileNotFoundError (versão 4)As duas funcionam. O try é o mais comum em Python ("é mais fácil pedir desculpas do que permissão"), e evita a pequena chance de o arquivo sumir entre a pergunta e o open
Guardar os contatosLista de dicionários · um dicionário {nome: telefone}A lista: cada contato pode ganhar mais campos (email, aniversário), e dois contatos podem ter o mesmo nome

Quando salvarA cada mudança · só ao sair (opção 0)A cada mudança: se o programa fechar de repente (Ctrl+C, falta de luz), nada se perde
Escolher quem removerPelo número da lista · pelo nomePelo número: nomes podem se repetir, e ninguém gosta de digitar "João Conceição" inteiro

  • Listar em ordem alfabética, com sorted(contatos, key=lambda c: c["nome"]) (aulas Ordenando Listas e lambda).
  • Avisar quando o nome já existe, antes de adicionar.
  • Confirmar a remoção: Remover Ana Souza? (s/n).

Resumo

  • Cada contato é um dicionário; a agenda é uma lista de dicionários.
  • O menu é um while True com input(), if/elif/else e um break para sair. Sem o break, o programa só termina com EOFError.
  • O que está na memória some quando o programa fecha. Para lembrar, json.dump grava a lista no contatos.json, e json.load lê de volta ao começar.
  • ensure_ascii=False (com encoding="utf-8") guarda João Conceição em vez de João Conceição.
  • Os erros de quem usa o programa viram mensagens: FileNotFoundError (começa vazio), JSONDecodeError (avisa e sai sem apagar nada), ValueError (número inválido). E a faixa do número é conferida antes do pop, porque pop(-1) apaga o último sem erro.
