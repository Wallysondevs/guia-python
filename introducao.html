Python Introdução

O Python (lê-se "páiton") é uma linguagem de programação criada para ser fácil de ler e de escrever. Um programa em Python parece quase uma lista de instruções em inglês simples, e por isso ele é a primeira linguagem de muita gente, de crianças na escola a cientistas. Mas não se engane com a simplicidade: o mesmo Python roda sites enormes, analisa dados de empresas, controla robôs e treina inteligências artificiais. Nesta aula você vai entender o que é programar, como o Python funciona por dentro, de onde ele veio e onde ele está hoje.

Primeiro: o que é programar?

Um computador não "entende" nada sozinho. Ele só sabe seguir instruções, uma de cada vez, muito rápido. Programar é escrever essas instruções. Uma linguagem de programação é o idioma combinado entre você e o computador: um conjunto pequeno de palavras e símbolos, com regras rígidas sobre onde cada coisa vai.

Pense numa receita de bolo. Ela tem uma lista de passos, em ordem: "pré-aqueça o forno", "misture os ovos com o açúcar", "se a massa estiver grossa, acrescente leite", "bata até ficar lisa". Um programa é igual: uma lista de passos, alguns com decisões ("se…") e outros com repetições ("até…"). A diferença é que o computador segue a receita ao pé da letra. Uma pessoa entende "açucar" sem acento; o computador, não. Se você escrever prnt em vez de print, ele não adivinha o que você quis dizer: ele para e reclama. Essas reclamações são as mensagens de erro, e este guia vai ensinar você a ler cada uma delas.

Veja um programa Python de verdade. É a lista de compras da Ana:

compras = ["arroz", "feijão", "café"]
for item in compras:
    print("Comprar:", item)

Mesmo sem saber nada de Python, dá para desconfiar do que ele faz: guarda três itens numa lista chamada compras e, para cada item (for item in compras), mostra na tela (print, "imprimir") a palavra "Comprar:" e o item. A Ana rodou o programa no terminal do computador dela:

$ python3 lista.py
Comprar: arroz
Comprar: feijão
Comprar: café

Você não precisa entender cada detalhe agora: a lista tem aula própria (Listas), o for também (for), e o print é o assunto de print(). Por enquanto, repare em como o programa é curto e quase se lê em voz alta.

Você mesmo pode rodar esse programa aqui, sem instalar nada. As caixas Experimente do guia rodam Python de verdade, dentro do navegador (a aula O Editor do Guia mostra tudo o que elas fazem):

Missão: rode o programa como está. Depois, acrescente "leite" à lista (dentro dos colchetes, depois de "café", separado por vírgula) e rode de novo: deve aparecer uma quarta linha, Comprar: leite.

compras = ["arroz", "feijão", "café"]
for item in compras:
    print("Comprar:", item)

compras = ["arroz", "feijão", "café", "leite"]
for item in compras:
    print("Comprar:", item)

Você mudou um dado (a lista) e o programa se adaptou sozinho, sem você mexer nas outras linhas. Essa é a graça de programar: escrever a receita uma vez e usá-la com outros ingredientes.

O Python é uma linguagem interpretada

O processador do computador (a CPU, o "cérebro") não entende português, nem inglês, nem Python. Ele só entende código de máquina: sequências de números que querem dizer coisas como "some estes dois valores" ou "guarde isto na memória". Alguém precisa traduzir o texto do programa para essa língua. Existem dois jeitos de fazer isso:

JeitoComo funcionaComparaçãoExemplos
CompilarUm programa chamado compilador traduz o texto inteiro antes, uma vez só, e gera um arquivo executável, que depois roda sozinho.Traduzir um livro inteiro e imprimir a tradução. Quem lê a versão traduzida não precisa do tradutor.C, C++, Rust, Go
InterpretarUm programa chamado interpretador lê o texto e vai executando as instruções, toda vez que o programa roda.Um intérprete numa palestra, traduzindo frase por frase enquanto a pessoa fala. Sem o intérprete na sala, ninguém entende.Python, JavaScript, PHP, Ruby

O Python é interpretado. O seu programa é um arquivo de texto comum, terminado em .py, e quem o executa é o interpretador, um programa que, no Linux, se chama python3. Foi ele que a Ana chamou no terminal (python3 lista.py): "interpretador, leia o arquivo lista.py e faça o que está escrito". A aula Rodando um Programa (.py) mostra isso passo a passo.

O interpretador mais usado (o que vem no Linux, o do site oficial e o do editor do guia) se chama CPython, porque é escrito na linguagem C. O próprio Python confirma:

$ python3 -c "import platform; print(platform.python_implementation())"
CPython

(O -c manda o python3 rodar o texto que vem logo depois, em vez de um arquivo. É um atalho para testar uma linha só.)

O lado bom e o lado ruim

A interpretação traz uma vantagem enorme para quem está aprendendo: você escreve, roda e vê o resultado na hora, sem uma etapa de compilação no meio. Dá até para conversar com o Python linha por linha, no modo interativo (>>>). O preço é a velocidade: em contas muito pesadas, um programa Python costuma ser bem mais lento que o mesmo programa em C. Na prática, isso raramente atrapalha, porque as bibliotecas que fazem o trabalho pesado (de ciência de dados e de inteligência artificial, por exemplo) são escritas em C por baixo, e o Python só "dá as ordens".

Uma tradução escondida

Para ser exato: antes de executar, o CPython traduz o seu programa para um formato intermediário, o bytecode, que é mais rápido de executar do que o texto. Isso acontece sozinho, em milésimos de segundo, toda vez que você roda o programa. Às vezes você vai ver uma pasta chamada __pycache__ aparecer ao lado dos seus arquivos: é ali que o Python guarda essa tradução para reaproveitar. Pode ignorar (ou apagar; ele refaz quando precisar).

Por que dizem que o Python é fácil

Compare o programa mais simples que existe, o que escreve uma frase na tela, em duas linguagens. Em C:

#include <stdio.h>

int main(void) {
    printf("Olá, mundo!\n");
    return 0;
}

Em Python:

print("Olá, mundo!")

$ python3 ola.py
Olá, mundo!

Uma linha. Sem #include, sem main, sem chaves, sem ponto e vírgula, sem compilar. Isso não quer dizer que o C seja ruim (ele é ótimo no que faz: veja o Guia C), mas mostra a escolha do Python: deixar o programa limpo, para que você pense no problema, e não na pontuação.

Três características explicam essa fama:

  • Pouca pontuação. Onde outras linguagens usam chaves { } para agrupar instruções, o Python usa a própria indentação (o recuo do texto na linha). O programa é obrigado a ficar organizado. A aula Sintaxe e Indentação explica essa regra, que é a mais famosa do Python.
  • Palavras em inglês simples. if ("se"), for ("para"), in ("em"), and ("e"), not ("não"), True ("verdadeiro"). Muito programa Python se lê como uma frase.
  • "Pilhas incluídas" (batteries included). O Python vem com uma biblioteca padrão gigante: ferramentas prontas para datas, contas, arquivos, sorteios, internet, planilhas CSV e muito mais. Para muita coisa, você não precisa instalar nada além do próprio Python.

Um pouco de história

No Natal de 1989, o programador holandês Guido van Rossum trabalhava num instituto de pesquisa em Amsterdã, o CWI, e queria um projeto para passar o tempo nas férias. Ele resolveu criar uma linguagem nova, que fosse mais fácil de usar do que o C e mais poderosa do que os "scripts" do terminal. Em fevereiro de 1991, publicou a primeira versão.

E o nome? Não tem nada a ver com a cobra. Guido era fã do Monty Python's Flying Circus, um programa de humor britânico dos anos 1970, e queria um nome curto, diferente e um pouco misterioso. (A cobra do logotipo veio depois, porque era inevitável.) Até hoje a documentação oficial tem piadas do grupo escondidas nos exemplos: em vez de foo e bar, os nomes usados por programadores do mundo inteiro, ela usa spam e eggs, de um esquete famoso.

Python 2 e Python 3: por que o comando é python3

A troca do Python 2 para o Python 3 demorou mais de dez anos, e durante esse tempo os dois conviveram no mesmo computador. Para não confundir, o Linux passou a chamar o novo de python3. O Python 2 morreu, mas o nome ficou: no Ubuntu, o comando é python3, e o comando python, sozinho, nem existe (a aula Instalar o Python mostra o que acontece se você digitar). Os números depois do 3 são as versões: 3.12, 3.13, 3.14… Todas são "Python 3", e um programa escrito para uma roda nas seguintes quase sempre sem mudar nada.

A Ana conferiu a versão do computador dela:

$ python3 --version
Python 3.14.4                                       « Python 3, versão 3.14 (a revisão 4 da 3.14)

O Zen do Python

Em 1999, o programador Tim Peters resumiu a filosofia do Python em 19 frases curtas. Elas ficaram tão famosas que viraram parte da própria linguagem: estão guardadas dentro do Python, e aparecem quando você pede import this ("importe isto"):

$ python3 -c "import this"
The Zen of Python, by Tim Peters

Beautiful is better than ugly.
Explicit is better than implicit.
Simple is better than complex.
Complex is better than complicated.
Flat is better than nested.
Sparse is better than dense.
Readability counts.
Special cases aren't special enough to break the rules.
Although practicality beats purity.
Errors should never pass silently.
Unless explicitly silenced.
In the face of ambiguity, refuse the temptation to guess.
There should be one-- and preferably only one --obvious way to do it.
Although that way may not be obvious at first unless you're Dutch.
Now is better than never.
Although never is often better than *right* now.
If the implementation is hard to explain, it's a bad idea.
If the implementation is easy to explain, it may be a good idea.
Namespaces are one honking great idea -- let's do more of those!

Quando dá errado

Você ainda não escreveu programas, mas já dá para conhecer duas confusões muito comuns de quem está começando. E a primeira traz a sua primeira mensagem de erro de verdade.

Um código antigo, de Python 2

A Ana achou na internet um tutorial antigo, copiou o "Olá, mundo" de lá e salvou como antigo.py:

print "Olá, mundo!"

No Python 3, ele não roda:

$ python3 antigo.py
  File "/home/ana/antigo.py", line 1
    print "Olá, mundo!"
    ^^^^^^^^^^^^^^^^^^^
SyntaxError: Missing parentheses in call to 'print'. Did you mean print(...)?

As mensagens do Python saem em inglês, mesmo num computador em português. O guia traduz e explica cada uma. Esta, linha por linha:

File "/home/ana/antigo.py", line 1
"Arquivo /home/ana/antigo.py, linha 1": onde está o problema. O Python diz o arquivo e o número da linha.
print "Olá, mundo!"
A própria linha com problema, copiada do seu arquivo, para você não precisar procurar.
^^^^^^^^^^^^^^^^^^^
Os acentos circunflexos ficam embaixo do trecho exato que o Python não aceitou, como alguém sublinhando a palavra errada numa prova.
SyntaxError
O tipo do erro: "erro de sintaxe". Sintaxe é a gramática da linguagem; o Python não conseguiu nem entender a frase.
Missing parentheses in call to 'print'.
"Faltam os parênteses na chamada do print."
Did you mean print(...)?
"Você quis dizer print(...)?" O Python dá a dica do conserto.

O que aconteceu: no Python 2, o print era escrito sem parênteses. No Python 3, ele virou uma função, e toda função leva parênteses (aula print()). O tutorial era de antes de 2008.

Como resolver: coloque os parênteses: print("Olá, mundo!"). E, para estudar, prefira material de Python 3. Se um tutorial usa print sem parênteses, ele é de Python 2: procure outro.

"Dei dois cliques no arquivo .py e só abriu um texto"

O que aconteceu: nada de errado. Um arquivo .py é só texto, o "código-fonte" do programa. No Linux, dois cliques nele abrem um editor de texto, como abririam uma receita salva no computador. A receita não faz o bolo sozinha: alguém precisa ler e executar.

Como resolver: quem executa é o interpretador. Abra o terminal e rode python3 arquivo.py (aula Rodando um Programa (.py)), ou use as caixas Experimente do guia, que rodam o programa com um clique.

Missão: veja com os próprios olhos a mensagem do Python 2. Apague os dois parênteses do print (deixe print "Olá, mundo!") e clique em Rodar. A caixa deve mostrar o SyntaxError com a dica Did you mean print(...)?. Depois, ponha os parênteses de volta e rode de novo.

print("Olá, mundo!")

print "Olá, mundo!"

Errar de propósito é um ótimo jeito de aprender: você fica conhecendo a mensagem antes de precisar dela de verdade.

Resumo

  • Programar é escrever instruções, como uma receita que o computador segue ao pé da letra; quando algo não faz sentido, ele mostra uma mensagem de erro.
  • O Python é interpretado: o programa é um arquivo de texto .py, e quem o executa é o interpretador python3 (o CPython, escrito em C).
  • Ele é famoso por ser fácil de ler: pouca pontuação, indentação no lugar das chaves, palavras em inglês simples e uma biblioteca padrão enorme.
  • Foi criado por Guido van Rossum, a partir de 1989 (primeira versão em 1991). O nome vem do Monty Python, não da cobra.
  • O Python 2 acabou em 2020. Hoje tudo é Python 3, e o comando no Linux é python3. Este guia ensina o 3.14.
  • Ele está na automação, na ciência de dados, na inteligência artificial, em sites, no próprio Ubuntu e nas escolas.
  • As mensagens de erro saem em inglês e dizem o arquivo, a linha, o trecho (^^^^), o tipo do erro e, muitas vezes, uma dica.
  • Próximo passo: ter o Python no seu computador, em Instalar o Python.
