A explicação passo a passo de cada grupo está nas aulas, a partir de Operadores Aritméticos.

Como ler as tabelas

  • Alguns exemplos usam variáveis: elas aparecem logo acima da tabela.

Bit a bit

Com números inteiros, estes operadores trabalham com os bits: os zeros e uns com que o computador escreve o número. bin(n) mostra os bits (bin(6) é '0b110': 4 + 2), e 0b110 escreve um número direto em binário. O operador morsa :=

O := ("expressão de atribuição", apelidada de operador morsa, porque o sinal lembra os olhos e as presas de uma morsa) guarda um valor numa variável e devolve esse valor, no meio de uma expressão. Serve para não calcular a mesma coisa duas vezes:

nome = "Ana Beatriz"
if (tamanho := len(nome)) > 5:
    print(f"Nome comprido: {tamanho} letras")

$ python3 ro_morsa.py
Nome comprido: 11 letras

O len(nome) foi calculado uma vez, guardado em tamanho, comparado com 5 e usado de novo no print. Os parênteses em volta são necessários: sem eles, o :=, que é o operador mais fraco de todos, pegaria len(nome) > 5 inteiro, e tamanho valeria True.

O @: multiplicação de matrizes

O @ existe na linguagem desde o Python 3.5, mas nenhum tipo que vem com o Python o usa. Ele foi criado para as bibliotecas de cálculo, como a NumPy, em que a @ b multiplica duas matrizes (tabelas de números). Com números comuns, dá erro:

print(2 @ 3)

$ python3 ro_matmul.py
Traceback (most recent call last):
  File "/home/ana/ro_matmul.py", line 1, in <module>
    print(2 @ 3)
          ~~^~~
TypeError: unsupported operand type(s) for @: 'int' and 'int'

"Tipos não suportados para @: int e int". Um tipo passa a aceitar o @ quando define o método especial __matmul__ (aula Métodos Especiais). Um exemplo pequeno, só para ver funcionando:

class Matriz:
    def __init__(self, linhas):
        self.linhas = linhas
    def __matmul__(self, outra):
        a, b = self.linhas, outra.linhas
        return Matriz([[sum(a[i][k] * b[k][j] for k in range(len(b)))
                        for j in range(len(b[0]))] for i in range(len(a))])
m = Matriz([[1, 2], [3, 4]])
id2 = Matriz([[1, 0], [0, 1]])
print((m @ id2).linhas)
print((m @ m).linhas)

$ python3 ro_matriz.py
[[1, 2], [3, 4]]
[[7, 10], [15, 22]]

Não se preocupe em entender a classe agora. Na prática, você só vai escrever @ se um dia trabalhar com matrizes numa biblioteca.

Precedência: quem é feito primeiro

Quando uma expressão tem vários operadores, o Python faz primeiro os mais fortes. A tabela abaixo é a da documentação oficial (docs.python.org, seção 6.17), do mais forte (feito primeiro) para o mais fraco (feito por último). Operadores da mesma linha têm a mesma força e são feitos da esquerda para a direita, menos a potência ** e o if/else, que vão da direita para a esquerda. Na dúvida, parênteses

Ninguém precisa decorar as 18 linhas. Quando a ordem não for óbvia para quem lê, ponha parênteses: (nota1 + nota2) / 2 e (-2) ** 2 deixam a intenção clara e não custam nada.

Experimente

Missão: a média de 8 e 6 deveria ser 7.0, mas o programa mostra Média: 11.0, porque a divisão foi feita antes da soma. Ponha os parênteses no lugar certo.

nota1 = 8
nota2 = 6
media = nota1 + nota2 / 2
print("Média:", media)

nota1 = 8
nota2 = 6
media = (nota1 + nota2) / 2
print("Média:", media)

Livre: o caixa da padaria com o operador morsa. O while lê um preço, guarda em texto e já compara com o vazio, tudo na mesma linha. A caixa digita sozinha 0.50, 4.75 e uma linha vazia. Rode e depois mude o programa à vontade: por exemplo, conte quantos produtos passaram.

total = 0
while (texto := input("Preço (vazio para parar): ")) != "":
    total += float(texto)
print(f"Total: R$ {total:.2f}")

Resumo

  • Aritméticos: + - * / // % **. / sempre dá float; // arredonda para baixo; ** é potência (não ^).
  • Comparação: == != < <= > >=, que podem ser encadeadas (1 < x < 5).
  • Lógicos: and, or, not; and/or devolvem um dos valores (nome or "anônimo").
  • is pergunta se é o mesmo objeto (use com None); in pergunta se está dentro (no dicionário, só nas chaves).
  • Bit a bit: & | ^ ~ << >>; com conjuntos, | & - ^ são união, interseção e diferenças.
  • Atribuição: = e as formas +=, -=…; o morsa := guarda e devolve um valor dentro de uma expressão.
  • @ é para matrizes em bibliotecas; nos tipos do Python dá TypeError.
  • Precedência: parênteses, **, sinal, * / // %, + -, bits, comparações, not, and, or, if/else, lambda, :=. Na dúvida, parênteses.
