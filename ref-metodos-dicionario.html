Python Métodos de Dicionário

Esta é a página de consulta rápida dos métodos de dicionário: as funções que todo dicionário (dict) já traz, para ler valores sem erro, ver as chaves e os valores, acrescentar, juntar e remover. São 11. No fim estão também as operações com dicionários que não são métodos (d[chave], in, del, |). A explicação passo a passo começa na aula Dicionários.

Como ler as tabelas
  • Exemplo é o que você digitaria depois do >>> do modo interativo, uma linha depois da outra; Resultado é o que o Python 3.14.4 respondeu no computador da Ana.
  • Quase todos os exemplos usam os preços da padaria: precos = {"pão": 0.5, "leite": 4.0, "café": 18.9}. Cada par "pão": 0.5 é uma chave ("pão") e o seu valor (0.5).
  • Os dicionários guardam a ordem em que as chaves entraram, e os resultados aparecem sempre nessa ordem.
  • Quando o exemplo dá erro, o resultado mostra a última linha da mensagem do Python (em inglês).
O erro mais comum: a chave que não existe

Ler com colchetes uma chave que não está no dicionário dá KeyError. O método get lê sem esse risco:

$ python3 -q
>>> precos = {"pão": 0.5, "leite": 4.0, "café": 18.9}
>>> precos["mel"]
Traceback (most recent call last):
  File "<python-input-1>", line 1, in <module>
    precos["mel"]
    ~~~~~~^^^^^^^
KeyError: 'mel'
>>> precos.get("mel", 0)
0
>>> exit()

KeyError: 'mel' = "erro de chave: 'mel'": a mensagem é só o nome da chave que faltou. O get("mel", 0) devolveu o valor padrão 0 em vez de quebrar o programa.

O que é uma "vista"

keys(), values() e items() não fazem uma cópia: são uma janela para o dicionário, que acompanha as mudanças nele. Dá para usá-las num for, com in, len, sum e sorted. Para ter uma lista de verdade (e usar [0], por exemplo), ponha dentro de list().

fromkeys com uma lista como valor

Em dict.fromkeys(nomes, []), todas as chaves recebem a mesma lista: acrescentar algo na lista de uma acrescenta em todas. Com d = dict.fromkeys(["Ana", "Bia"], []) e depois d["Ana"].append(7), o d fica {'Ana': [7], 'Bia': [7]}. Para uma lista nova em cada chave, use {nome: [] for nome in nomes}.

Que valores podem ser chave?

Textos, números, True/False e tuplas (de valores que não mudam). Listas, dicionários e conjuntos não, porque podem mudar. No Python 3.14, a mensagem de erro ficou mais clara: {[1, 2]: "x"} dá TypeError: cannot use 'list' as a dict key (unhashable type: 'list') = "não dá para usar uma lista como chave de dicionário". 3.14 No 3.13, a mesma linha dizia só unhashable type: 'list'. Veja Mutável × Imutável.

Missão: a Ana fez uma votação do lanche da turma e quer contar os votos. Rode e veja o KeyError: no primeiro voto, a chave 'pão' ainda não existe. Conserte a linha do laço usando contagem.get(voto, 0) no lugar de contagem[voto] (só do lado direito do =). A saída deve ser {'pão': 3, 'bolo': 2, 'café': 1}.

votos = ["pão", "bolo", "pão", "café", "pão", "bolo"]
contagem = {}
for voto in votos:
    contagem[voto] = contagem[voto] + 1
print(contagem)

contagem = {}

Livre: o estoque da padaria. Acrescente produtos com update, tire outros com pop, troque "mel" por "pão" na última linha.

estoque = {"pão": 30, "leite": 12, "café": 5}
estoque.update({"leite": 10, "ovo": 24})
vendido = estoque.pop("café")
print("Café saiu do estoque:", vendido, "pacotes")
for produto, quantidade in estoque.items():
    print(f"{produto:<6} {quantidade:>3}")
print("Total de itens:", sum(estoque.values()))
print("Tem mel?", "mel" in estoque, "- quantidade:", estoque.get("mel", 0))

Resumo

  • Ler: d[chave] dá KeyError se a chave falta; d.get(chave, padrão) não dá.
  • Ver: keys(), values(), items() (este, no for chave, valor in d.items():). in procura só nas chaves.
  • Acrescentar e trocar: d[chave] = valor, update, |=; setdefault cria só se faltar.
  • Remover: pop(chave) devolve o valor; popitem() tira o último par; del d[chave]; clear().
  • Criar: dict.fromkeys, dict(zip(…)), dict comprehension; copiar com copy(); juntar com a | b.
  • Chaves precisam ser valores que não mudam: listas não podem ser chave.
