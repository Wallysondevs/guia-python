Python Dicionários Aninhados

A Ana virou professora de reforço e precisa de um cadastro dos alunos: de cada um, a idade, a cidade e as notas. Um dicionário simples guarda um valor por chave. Mas o valor pode ser de qualquer tipo, inclusive outro dicionário. Quando um dicionário guarda outros dicionários (e listas) dentro dele, dizemos que eles estão aninhados, como caixas dentro de caixas. É assim que se monta um cadastro de verdade.

Você vai aprender
  • A montar um cadastro: um dicionário de alunos em que cada aluno é outro dicionário.
  • A ler um dado lá de dentro, um colchete por nível: alunos["Ana"]["notas"][0].
  • A acrescentar alunos, mudar a idade e lançar notas por dentro.
  • A percorrer o cadastro e calcular a média de cada aluno.
  • A diferença entre dicionário de dicionários e lista de dicionários.
  • A mostrar o cadastro arrumado com pprint.
  • Os erros reais de cada nível, e uma armadilha sem erro: dois alunos que dividem a mesma ficha.

A ideia: o fichário

Imagine um fichário de escritório. Cada gaveta tem o nome de um aluno. Dentro da gaveta há uma ficha com campos: idade, cidade, notas. E o campo "notas" é uma lista, uma nota atrás da outra. Para achar a primeira nota da Ana, você abre a gaveta "Ana", pega a ficha, olha o campo "notas" e lê a primeira da lista. Três passos, um em cada nível.

NívelNo fichárioEm PythonTipo
1O fichário inteiroalunosDicionário (chave: nome do aluno)
2A ficha da Anaalunos["Ana"]Dicionário (chave: nome do campo)
3O campo notasalunos["Ana"]["notas"]Lista
4A primeira notaalunos["Ana"]["notas"][0]Número

Lendo da esquerda para a direita

Uma linha como alunos["Bia"]["notas"][-1] assusta no começo, mas o Python a resolve da esquerda para a direita, um colchete de cada vez. Dá para fazer o mesmo em passos, guardando cada nível numa variável:

alunos = {
    "Ana": {"idade": 15, "cidade": "Teresina", "notas": [9, 7, 10]},
    "Bia": {"idade": 16, "cidade": "Picos", "notas": [6, 8, 7]},
}
ficha = alunos["Bia"]
notas = ficha["notas"]
print(ficha)
print(notas)
print(notas[-1])

$ python3 n_passos.py
{'idade': 16, 'cidade': 'Picos', 'notas': [6, 8, 7]}
[6, 8, 7]
7

notas[-1] é exatamente o mesmo que alunos["Bia"]["notas"][-1]. Quando uma linha com muitos colchetes não funcionar, quebrá-la assim, com um print em cada passo, mostra em qual nível está o problema.

3. Percorrendo o cadastro

Com items() (aula Percorrendo um Dicionário), cada volta do for entrega o nome do aluno e a ficha dele. Da ficha você tira o que precisar, como a lista de notas para calcular a média:

alunos = {
    "Ana": {"idade": 15, "cidade": "Teresina", "notas": [9, 7, 10]},
    "Bia": {"idade": 16, "cidade": "Picos", "notas": [6, 8, 7]},
    "Caio": {"idade": 15, "cidade": "Parnaíba", "notas": [10, 9]},
}
for nome, dados in alunos.items():
    media = sum(dados["notas"]) / len(dados["notas"])
    print(f"{nome} ({dados['cidade']}): média {media:.1f}")

Caio (Parnaíba): média 9.5

A cada volta, nome recebe a chave ("Ana") e dados recebe a ficha inteira (o dicionário de dentro).
dados["notas"]
Como dados já é a ficha, basta um colchete para chegar às notas.
sum(…) / len(…)
A soma das notas dividida pela quantidade: a média. O Caio tem só duas notas, e a conta funciona do mesmo jeito.
{dados['cidade']}
Dentro da f-string com aspas duplas, a chave vai com aspas simples.

Três níveis de dicionário

Nada impede mais níveis. Uma escola com turmas, cada turma com alunos, cada aluno com notas:

escola = {
    "1A": {
        "Ana": {"notas": [9, 7, 10]},
        "Bia": {"notas": [6, 8, 7]},
    },
    "1B": {
        "Caio": {"notas": [10, 9]},
    },
}
print(escola["1A"]["Bia"]["notas"][1])
for turma, alunos in escola.items():
    print(f"Turma {turma}: {len(alunos)} aluno(s)")

$ python3 n_tres.py
8

Turma 1B: 1 aluno(s)

Funciona, mas cada nível a mais é um colchete a mais para lembrar. Dois ou três níveis costumam bastar; se passar disso, é sinal de que vale a pena organizar de outro jeito (as classes, mais adiante no guia, são uma forma).

5. Mostrando arrumado e lendo com cuidado

O pprint

Com o print comum, um cadastro inteiro sai numa linha só, comprida. O Python tem uma ferramenta pronta para mostrar estruturas aninhadas arrumadas: o pprint ("pretty print", impressão bonita). Ele fica num módulo que você precisa trazer com import (o assunto da aula Módulos e import); por enquanto, basta copiar a primeira linha:

from pprint import pprint
alunos = {
    "Ana": {"idade": 15, "cidade": "Teresina", "notas": [9, 7, 10]},
    "Bia": {"idade": 16, "cidade": "Picos", "notas": [6, 8, 7]},
}
print(alunos)
pprint(alunos, width=40, sort_dicts=False)

get em cada nível

Para um aluno que pode não existir, ou um campo que nem toda ficha tem, use get. E para encadear, dê como padrão um dicionário vazio {}, que aceita o próximo get:

alunos = {
    "Ana": {"idade": 15, "cidade": "Teresina", "notas": [9, 7, 10]},
}
print(alunos.get("Davi"))
print(alunos.get("Davi", {}).get("cidade"))
print(alunos.get("Ana", {}).get("cidade"))
print(alunos["Ana"].get("email", "sem email"))

Quando dá errado

Com vários níveis, a pergunta mais importante diante de um erro é: em qual colchete ele aconteceu? Os sinais ~~~^^^ que o Python mostra embaixo da linha respondem: os ^ ficam embaixo do colchete que falhou.

Campo com o nome errado

    "Ana": {"idade": 15, "cidade": "Teresina", "notas": [9, 7, 10]},

~~~~~~~~~~~~~^^^^^^^^
Os tils cobrem alunos["Ana"] (essa parte deu certo) e os ^ ficam embaixo de ["nota"]: foi no segundo nível, dentro da ficha da Ana.
KeyError: 'nota'
A ficha não tem o campo 'nota'. Ela tem 'notas', no plural.

Como consertar: alunos["Ana"]["notas"]. Na dúvida sobre os nomes dos campos, mostre a ficha: print(alunos["Ana"].keys()).

Dois alunos com a mesma ficha: sem erro, resultado errado

Para não repetir, a Ana criou uma ficha "modelo" e usou para os dois alunos novos:

modelo = {"idade": 15, "notas": []}
alunos = {}
alunos["Ana"] = modelo
alunos["Bia"] = modelo
alunos["Ana"]["notas"].append(9)
print(alunos)

$ python3 n_compartilhado.py
{'Ana': {'idade': 15, 'notas': [9]}, 'Bia': {'idade': 15, 'notas': [9]}}

Ela lançou a nota só para a Ana, e a Bia também ganhou um 9! alunos["Ana"] = modelo não copiou a ficha: guardou a mesma ficha nas duas gavetas. É uma ficha só, com dois nomes na etiqueta; mexeu por uma gaveta, aparece pela outra. Como consertar: crie uma ficha nova para cada aluno, por exemplo dentro de um for:

alunos = {}
for nome in ["Ana", "Bia"]:
    alunos[nome] = {"idade": 15, "notas": []}
alunos["Ana"]["notas"].append(9)
print(alunos)

$ python3 n_compartilhado_ok.py
{'Ana': {'idade': 15, 'notas': [9]}, 'Bia': {'idade': 15, 'notas': []}}

A cada volta, {"idade": 15, "notas": []} cria um dicionário e uma lista novos. Por que isso acontece, e por que até modelo.copy() não resolveria (a lista de notas continuaria dividida), é o assunto da aula Cópia Rasa e Cópia Profunda.

Resumo

  • Um dicionário pode guardar outros dicionários e listas: é um dicionário aninhado, como um fichário com fichas e campos.
  • Para ler lá de dentro, um colchete por nível, da esquerda para a direita: alunos["Ana"]["notas"][0]. Chave onde é dicionário, posição onde é lista.
  • Para mudar, chegue ao nível certo e use a operação de sempre: = valor, .append(), del.
  • for nome, dados in alunos.items(): entrega cada ficha inteira em dados.
  • Dicionário de dicionários para achar por uma chave única; lista de dicionários para percorrer e ordenar.
  • pprint(d, sort_dicts=False) mostra arrumado; d.get("a", {}).get("b") lê sem erro.
  • Num erro, os ^ mostram qual colchete falhou. E cuidado: usar o mesmo dicionário para dois itens faz os dois mudarem juntos.
