Projeto Jogo da Forca

O jogo da forca de caderno, agora no terminal: o computador escolhe uma palavra e mostra só os tracinhos, um para cada letra. Você chuta letras; cada acerto revela a letra em todos os lugares onde ela aparece, e cada erro desenha mais uma parte do boneco. Seis erros e o boneco está completo: você perdeu. É o projeto ideal para praticar textos e listas juntos.

Você vai praticar
  • Percorrer um texto letra por letra com for e montar outro texto aos poucos com += (Operadores de Atribuição).
  • Perguntar "está dentro?" com in e not in, em textos e em listas.
  • Guardar as letras certas e erradas em listas com append().
  • Validar o chute com strip(), lower(), isalpha() e count(), e pular com continue.
  • Desenhar o boneco com o if em uma linha e o escape \\.
  • Sortear a palavra com random.choice() e, no fim, ler as palavras de um arquivo.

Cinco versões, uma novidade em cada:

  1. A palavra escondida (percorrer o texto, a lista certas).
  2. Erros contados: dá para perder (a lista erradas, len).
  3. Chute validado (strip, lower, isalpha, continue).
  4. Funções, desenho e palavra sorteada (def, random.choice).
  5. As palavras num arquivo (open e with).

Antes de começar

Você vai usar strings, listas, while True com break (como na Calculadora) e random (como no Jogo de Adivinhação). Crie a pasta; o arquivo vai se chamar forca.py:

Versão 1 · A palavra escondida

Primeiro, só o coração do jogo: a palavra fixa "banana", os tracinhos e as letras aparecendo. Sem erros, sem forca: o jogo termina quando a palavra inteira estiver descoberta.

A ideia: o programa guarda numa lista as letras que a pessoa já acertou. A cada volta, ele monta a "máscara" da palavra do zero: passa letra por letra de "banana" e, para cada uma, pergunta "esta letra já foi acertada?". Se sim, escreve a letra; se não, escreve _.

Versão 4 · Funções, desenho e palavra sorteada

Hora de virar jogo de verdade: a palavra é sorteada de uma lista de frutas com random.choice(), e o boneco aparece na forca, uma parte por erro. Com tanta coisa, o programa ganha três funções: uma desenha, uma monta a máscara e uma lê a letra.

import random

PALAVRAS = ["abacaxi", "acerola", "banana", "caju", "goiaba",
            "laranja", "melancia", "morango", "pitanga"]
MAX_ERROS = 6


def desenhar(erros):
    """Desenha a forca com as partes do boneco que já apareceram."""
    cabeca = "O" if erros >= 1 else " "
    tronco = "|" if erros >= 2 else " "
    braco_esq = "/" if erros >= 3 else " "
    braco_dir = "\\" if erros >= 4 else " "
    perna_esq = "/" if erros >= 5 else " "
    perna_dir = "\\" if erros >= 6 else " "
    print("  +---+")
    print(f"  {cabeca}   |")
    print(f" {braco_esq}{tronco}{braco_dir}  |")
    print(f" {perna_esq} {perna_dir}  |")
    print("      |")
    print("=======")


def mascarar(palavra, certas):
    """Devolve a palavra com _ no lugar das letras ainda não descobertas."""
    mascara = ""
    for letra in palavra:
        if letra in certas:
            mascara += letra + " "
        else:
            mascara += "_ "
    return mascara.strip()


def ler_letra(tentadas):
    """Pergunta até a pessoa digitar uma letra que ainda não tentou."""
    while True:
        chute = input("Letra: ").strip().lower()
        if len(chute) != 1 or not chute.isalpha():
            print("Digite uma letra só.")
        elif chute in tentadas:
            print(f"Você já tentou a letra {chute}.")
        else:
            return chute


palavra = random.choice(PALAVRAS)
certas = []
erradas = []

print("=== Jogo da Forca: frutas ===")
while True:
    desenhar(len(erradas))
    mascara = mascarar(palavra, certas)
    print(mascara)
    if erradas:
        print("Erradas:", ", ".join(erradas))

    if "_" not in mascara:
        print(f"Você venceu! A palavra era {palavra}.")
        break
    if len(erradas) == MAX_ERROS:
        print(f"Você perdeu! A palavra era {palavra}.")
        break

    chute = ler_letra(certas + erradas)
    if chute in palavra:
        certas.append(chute)
        print(f"Tem {palavra.count(chute)} letra(s) {chute}!")
    else:
        erradas.append(chute)
        print(f"Não tem {chute}.")

random.choice(PALAVRAS)"Escolha": sorteia um item da lista. Cada fruta tem a mesma chance.
cabeca = "O" if erros >= 1 else " "Um if em uma linha: vale "O" se já houve 1 erro, senão um espaço. Cada parte do boneco tem a sua linha, e aparece a partir do seu número de erros.
"\\"A barra invertida sozinha. Dentro de um texto, \ começa um escape (como \n), então, para escrever uma barra, escrevem-se duas (veja Caracteres de Escape).
return mascara.strip()A função devolve a máscara, sem o espaço que sobrava no fim.
ler_letra(certas + erradas)O + entre duas listas cria uma lista nova com os itens das duas: todas as letras já tentadas.

Testando com a semente

Formas diferentes de montar a máscara

O for com += das versões 1 a 4 é o jeito mais fácil de entender. Programadores experientes costumam escrever a mesma coisa numa linha só, com join e o if em uma linha dentro de uma list comprehension:

$ python3
Python 3.14.4 (main, Aug 20 2026, 10:41:58) [GCC 15.2.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> palavra = "banana"
>>> certas = ["a", "n"]
>>> " ".join([letra if letra in certas else "_" for letra in palavra])
'_ a n a n a'
>>> " ".join(letra if letra in certas else "_" for letra in palavra)
'_ a n a n a'
>>> exit()

Lendo de dentro para fora: "para cada letra da palavra, use a letra se ela estiver em certas, senão "_""; depois, o " ".join junta tudo com espaços (e já sem o espaço sobrando no fim). A segunda forma, sem os colchetes, dá o mesmo resultado: quando a "comprehension" é o único argumento da função, os colchetes podem sair (ela vira uma expressão geradora, assunto da aula Geradores).

FormaQuando usar
for com mascara += …Quando você está aprendendo, ou quando cada passo precisa de mais de uma linha. É a forma mais clara.
" ".join([… for letra in palavra])Quando a regra cabe numa linha e você já lê comprehensions com facilidade.
Listas (certas, erradas)Guardam a ordem das tentativas, que o jogo mostra em "Erradas: e, o, r".
Um conjunto (set())Se a ordem não importasse: o in num conjunto é mais rápido e ele nunca repete itens. Numa forca, com poucas letras, tanto faz.

Ideias para continuar

  • Palavras com acento (maçã, pêssego): do jeito que está, a pessoa teria de digitar ã e ê. Uma saída é comparar sem acentos, com o módulo unicodedata da biblioteca do Python.
  • Chutar a palavra inteira: se o chute tiver mais de uma letra, compare com a palavra; acertou, venceu; errou, perde duas vidas.
  • Categorias: um arquivo por tema (frutas.txt, animais.txt), e o jogo pergunta qual tema a pessoa quer.
  • Jogar de novo, com placar de vitórias e derrotas, como no Jogo de Adivinhação.

  • O in pergunta "está dentro?"; entre textos, procura um pedaço (e o texto vazio está em todos).
  • len(erradas) conta os erros; o teste de derrota vem antes de pedir a próxima letra.
  • .strip().lower(), len(chute) == 1 e .isalpha() garantem uma letra só; continue recusa sem contar.
  • random.choice sorteia um item de uma lista; random.seed deixa o sorteio previsível para testar.
  • Guardar os dados num arquivo (palavras.txt) separa o jogo do conteúdo. Leia com with open(…, encoding="utf-8").
