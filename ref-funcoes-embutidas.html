Python Funções Embutidas

Esta é a página de consulta rápida das funções embutidas (em inglês, built-in functions): as 71 funções que já vêm prontas no Python 3.14 e funcionam em qualquer programa, sem import. Elas estão agrupadas pelo que fazem: mostrar, converter, fazer contas, percorrer listas, examinar objetos e rodar código. Cada linha traz um exemplo curto e o resultado que ele dá de verdade. A explicação passo a passo das mais usadas, com exercícios, está na aula Funções Embutidas (len, sum, max…).

Como ler as tabelas
  • Exemplo é o que você digitaria depois do >>> do modo interativo.
  • Resultado é o que o Python 3.14.4 respondeu no computador da Ana. Textos aparecem entre aspas ('Ana'), como o modo interativo mostra; com print() as aspas não aparecem.
  • Quando o exemplo dá erro, o resultado mostra a última linha da mensagem (o tipo do erro e a explicação, em inglês). A mensagem completa, com o Traceback, aparece logo abaixo.
  • Algumas "funções" da lista, como int, str e list, são na verdade classes (tipos). Você as chama como funções para criar ou converter valores, e por isso a documentação oficial as põe na mesma lista.
  • Resultados com 0x… (endereços na memória) mudam a cada execução.

Assim fica no terminal. Repare como o Python, quando dá erro, sublinha a parte da linha que falhou (~~~^^^^):

Novo no 3.14: float.from_number() 3.14

O Python 3.14 ganhou float.from_number(x) e complex.from_number(x): convertem um número e recusam texto (dão TypeError), ao contrário de float("7.5"). No lab: float.from_number(5) deu 5.0. Elas não estão na lista de funções embutidas (são métodos dos tipos float e complex), e não existem no Python 3.13.

Por que tanto list(…)?

reversed, enumerate, zip, map e filter não montam a lista inteira de uma vez: entregam um item por vez, quando você pede (num for, por exemplo). Por isso gastam pouca memória. Para ver todos os itens no modo interativo, ponha dentro de list(). Num for, use direto: for i, item in enumerate(lista):.

class Conta:
    def __init__(self, saldo):
        self._saldo = saldo

    @property
    def saldo(self):
        return self._saldo

    @classmethod
    def vazia(cls):
        return cls(0)

    @staticmethod
    def taxa():
        return 2.5

class Poupanca(Conta):
    def __init__(self, saldo):
        super().__init__(saldo)
        self.juros = 0.5

print(Conta(100).saldo)
print(Conta.vazia().saldo)
print(Conta.taxa())
print(Poupanca(50).saldo)

Nunca use eval ou exec com o que o usuário digitou

eval(input()) roda qualquer código que a pessoa digitar, inclusive um que apague arquivos. Para transformar o que foi digitado em número, use int() ou float().

Só no modo interativo: exit, quit, copyright, credits, license

Estes cinco nomes também existem sem import, mas não estão na lista oficial de funções embutidas: o Python os acrescenta ao começar, para o modo interativo. exit() e quit() saem do >>>. Num programa, para encerrar, use sys.exit() (veja Os Módulos os e sys).

E no Python 3.15?

A documentação do Python 3.15 (lançado em outubro de 2026) acrescenta duas funções embutidas à lista, que passa a ter 73: frozendict (um dicionário que não muda depois de criado, como o frozenset é para o set) e sentinel (para criar valores "marcadores" únicos). Elas não existem no Python 3.14, o do Ubuntu 26.04 e o do editor do guia; por isso esta página não traz exemplos delas. Veja Novidades do Python 3.14 e 3.15.

Não use esses nomes nas suas variáveis

Se você escrever sum = 0, list = [1, 2] ou max = 10, a função embutida fica escondida pela sua variável, e a próxima chamada dá TypeError: 'int' object is not callable. O caso completo está na aula Funções Embutidas. Prefira total, itens, maior.

Resumo

  • São 71 funções embutidas no Python 3.14: estão sempre disponíveis, sem import.
  • Mostrar e ler: print, input (que sempre devolve texto), repr, format.
  • Converter: int, float, str, bool, list, tuple, set, dict; e chr/ord entre letras e códigos.
  • Contas: abs, round (no meio vai para o par), pow, divmod, sum, min, max (com key= e default=).
  • Percorrer: len, sorted, reversed, enumerate, zip, map, filter, range, all, any. Várias devolvem um iterador: use list() para ver.
  • Examinar: type, isinstance, dir, vars, getattr/setattr/hasattr/delattr.
  • 3.14 map() ganhou strict=True; float.from_number() e complex.from_number() são novos.
