Experimente agora

A caixa abaixo é o editor Experimente do guia. Em cima fica o programa; clique em ▶ Rodar e o que ele escreve aparece embaixo, num terminal. Na primeira vez, o editor baixa o Python (uns 6 MB) e leva alguns segundos; depois, é na hora. Pode mexer à vontade: nada que você fizer aqui estraga o guia.

Missão: rode o programa como está e veja a lista de compras da Ana. Depois, ela lembrou que acabou a manteiga: acrescente "manteiga" na lista da primeira linha (depois de "café", com uma vírgula antes) e rode de novo.

compras = ["pão", "leite", "café"]
for item in compras:
    print("Comprar:", item)
print(f"Total de itens: {len(compras)}")

compras = ["pão", "leite", "café", "manteiga"]
for item in compras:
    print("Comprar:", item)
print(f"Total de itens: {len(compras)}")

O que aconteceu: você escreveu um programa, uma lista de instruções que o computador segue na ordem. Lido em voz alta, ele diz: "a lista de compras é pão, leite, café e manteiga; para cada item da lista, escreva 'Comprar:' e o item; no fim, escreva quantos itens a lista tem". O Python seguiu as instruções e escreveu uma linha por item. Você não precisou mudar o resto do programa: ele se adaptou sozinho à lista maior. Essa língua de instruções é o Python, e é isso que este guia ensina.

Se você esqueceu de fechar as aspas, viu uma mensagem em vermelho, em inglês: SyntaxError: unterminated string literal (detected at line 1) ("texto sem fim, encontrado na linha 1"). O Python não adivinha: ele diz exatamente onde não entendeu. E se esqueceu a vírgula, o Python não reclama, mas junta os dois textos num só: aparece Comprar: cafémanteiga e o total continua 3. Errar e ler o que o computador responde é metade do aprendizado: todas as aulas mostram os erros mais comuns, com a mensagem real e o jeito de consertar.

Um programa que conversa

Programas também podem perguntar. Rode a caixa, digite o seu nome no terminal dela (no campo que aparece depois da pergunta) e tecle Enter:

nome = input("Qual é o seu nome? ")
print(f"Olá, {nome}! Bem-vinda ao Python.")
print(f"O seu nome tem {len(nome)} letras.")

O que é este guia

Um programa é uma receita que o computador segue. O Python é uma das línguas mais usadas no mundo para escrever essas receitas, e uma das mais fáceis de ler: muitas linhas parecem frases em inglês. Com ele se fazem sites, planilhas automáticas, análise de dados, inteligência artificial, jogos e pequenos programas do dia a dia.

Quem aprende Python consegue:

  • fazer o computador repetir tarefas chatas: renomear cem arquivos, somar uma planilha, conferir uma lista;
  • tomar decisões no programa: "se a nota for maior que 7, aprovado; senão, recuperação";
  • guardar e organizar informações em listas e dicionários: o estoque da lojinha, a agenda de contatos;
  • ler e gravar arquivos de texto, planilhas CSV e JSON;
  • escrever programas grandes, divididos em funções, módulos e classes;
  • dar os próximos passos em análise de dados, sites ou automação, porque é o mesmo Python.

O guia é para quem nunca programou. Ele começa do zero absoluto (o que é um programa? como se roda um?) e vai até classes, geradores, decoradores, asyncio e testes. Cada aula ensina um assunto só, com calma. O Python das aulas é o 3.14, o do Ubuntu 26.04 e o do editor; quando algo mudou de uma versão para outra, uma nota avisa.

Como as aulas funcionam

Nenhum código aparece "seco". Toda aula segue o mesmo caminho:

  1. A ideia primeiro. Antes do código, você entende o problema que ele resolve, com uma comparação do dia a dia: uma receita de bolo, uma caixa com etiqueta, uma lista de compras.
  2. Anatomia. Cada parte de um comando novo é separada e explicada.
  3. A saída real. Depois de cada exemplo, o que o Python respondeu de verdade, no terminal. Nenhuma saída foi inventada.
  4. Experimente. Pelo menos duas caixas por aula para você mudar o código e rodar, muitas com uma missão que confere sozinha se você acertou.
  5. Várias formas de fazer. Quase sempre há mais de um jeito de escrever a mesma coisa, e uma tabela "qual usar" mostra quando escolher cada um.
  6. Quando dá errado. O código com erro e a mensagem real do Python (o traceback), traduzida e explicada linha por linha.
  7. Exercícios e resumo. Perguntas com correção na hora e uma lista curta do que levar da aula.

Exemplo: a anatomia de um programa

Veja como as aulas desmontam um programa. Primeiro o código, num arquivo chamado compras.py:

compras = ["pão", "leite", "café"]
for item in compras:
    print("Comprar:", item)
print(f"Total de itens: {len(compras)}")

Agora cada parte:

compras = [...]
Uma variável: um nome (compras) que guarda um valor. Aqui o valor é uma lista de três textos, entre colchetes (aulas Variáveis e Listas).
for item in compras:
"Para cada item em compras": repete o bloco de baixo uma vez para cada elemento da lista. Os dois-pontos no fim abrem o bloco (aula for).
print("Comprar:", item)
O bloco que se repete. Os 4 espaços no começo dizem ao Python que esta linha está "dentro" do for (aula Sintaxe e Indentação).
print(f"…{len(compras)}")
Sem recuo: roda uma vez só, depois do laço. O len conta os itens, e o f antes das aspas deixa pôr valores no meio do texto entre chaves (aula f-strings).

Exemplo: o terminal

Além do editor, as aulas mostram o terminal da máquina das aulas: um computador chamado notebook, da usuária ana. Lá, o programa fica no arquivo compras.py, e quem o roda é o comando python3:

$ python3 compras.py
Comprar: pão
Comprar: leite
Comprar: café
Total de itens: 3

A resposta é a mesma do editor, porque o Python é o mesmo nos dois lugares. A aula O Editor do Guia mostra tudo o que as caixas Experimente sabem fazer e o que muda no terminal, e Instalar o Python ensina a pôr o Python no seu computador.

Como estudar

Programar se aprende programando, como quem aprende a cozinhar cozinhando. Para cada aula, siga estes quatro passos:

  1. Leia com calma. Leia a ideia, a anatomia e a saída. Não pule a parte "Quando dá errado": quem entende a mensagem de erro conserta o problema em segundos.
  2. Mexa nos exemplos. Em toda caixa Experimente, mude um número, troque um texto, apague um pedaço de propósito e veja o que o Python responde. Não tem como estragar nada: cada Rodar começa do zero.
  3. Faça as missões. As caixas com Missão conferem sozinhas se você acertou. Tente de verdade antes de abrir a solução; se abrir, digite a solução você mesmo em vez de só olhar.
  4. Repita no seu computador. Quando chegar à aula Instalar o Python, instale-o e refaça os programas no terminal. Algumas coisas (instalar pacotes com pip, rodar outros programas, guardar arquivos de verdade) só existem lá.
A regra de ouro

Ler não basta: digite cada programa. Copiar e colar ensina pouco; digitar faz você reparar em cada aspa, cada dois-pontos e cada espaço do recuo. Comece pela aula O que é Python e, antes de ir longe, dê uma olhada em O Editor do Guia.

Versão de referência: Python 3.14

O guia ensina o Python 3.14. As saídas de terminal foram colhidas no Python 3.14.4 de um Ubuntu 26.04 em português do Brasil; o editor das aulas é o CPython 3.14.2 compilado para rodar no navegador (WebAssembly, pelo projeto Pyodide). Os dois são o mesmo Python: a linguagem, as mensagens de erro e as respostas são as mesmas. As mensagens de erro saem em inglês, exatamente como o Python as escreve, e as aulas as explicam em português. Se o seu computador tem uma versão mais antiga (o Debian 13, por exemplo, traz o 3.13), quase tudo funciona igual; as diferenças aparecem em notas.
