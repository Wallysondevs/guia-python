Projeto Contador de Palavras

A Ana escreveu uma crônica sobre um dia na padaria para o jornalzinho do bairro e ficou curiosa: qual palavra ela mais repetiu? Contar à mão, num texto de 150 palavras, já cansa; num livro, seria impossível. Neste projeto você escreve um programa que lê o texto de um arquivo, separa as palavras, conta quantas vezes cada uma aparece e mostra as 10 mais usadas, com uma barrinha para cada. No caminho aparecem os problemas de verdade: a vírgula grudada na palavra, o "O" maiúsculo que não é igual ao "o", as palavras pequenas que enchem a contagem.

Você vai praticar
  • Ler um arquivo de texto com open e with (aula Lendo Arquivos).
  • Separar e limpar o texto com split(), lower() e replace().
  • Contar com um dicionário e o método get, e depois com o Counter do módulo collections.
  • Ordenar pelo número de vezes com sorted() e uma lambda no key.
  • Filtrar palavras com list comprehension e um conjunto.
  • Alinhar a saída com f-strings e organizar o programa em funções.

O que vamos construir

Este é o resultado final, no computador da Ana, contando a crônica do arquivo cronica.txt:

$ python3 contador.py

quente       2 ##

rua          2 ##
pede         2 ##

"Pão" ganhou com folga, e "café" vem em segundo. Faz sentido para uma crônica de padaria. Vamos chegar lá em quatro versões, cada uma acrescentando uma coisa só:

  1. Ler o arquivo e separar as palavras (open, read, split).
  2. Limpar: minúsculas e sem pontuação (lower, replace).
  3. Contar com um dicionário e ordenar (get, sorted, lambda).
  4. Counter, palavras comuns e barras (Counter, most_common, conjunto).

Versão 2 · Limpar: minúsculas e sem pontuação

Duas limpezas, antes de separar: tudo em minúsculas, para "Pão" e "pão" virarem a mesma palavra; e cada sinal de pontuação trocado por um espaço, para a vírgula desgrudar da palavra. No fim, o programa confere se sobrou alguma "palavra" com algo que não é letra.

with open("cronica.txt", encoding="utf-8") as arquivo:
    texto = arquivo.read()

texto = texto.lower()
for sinal in PONTUACAO:
    texto = texto.replace(sinal, " ")

palavras = texto.split()
print(f"Palavras: {len(palavras)}")
print(palavras[:12])
com_sinais = [p for p in palavras if not p.isalpha()]
print(f"Palavras com sinais: {com_sinais}")
PONTUACAO = '.,;:!?"—'
Os sinais que aparecem na crônica, num texto só. O último é o travessão dos diálogos (—), que é diferente do hífen (-). O texto está entre aspas simples porque tem uma aspa dupla dentro.
texto.lower()
Devolve o texto em minúsculas. Funciona com acentos: "PÃO" vira "pão".
for sinal in PONTUACAO:
Um texto também pode ser percorrido com for, letra por letra (aqui, sinal por sinal).
texto.replace(sinal, " ")
Troca cada ocorrência do sinal por um espaço. Por que espaço, e não nada? Porque em "seis.Antes" (sem espaço depois do ponto) as duas palavras grudariam. O split() depois ignora os espaços a mais.
[p for p in palavras if not p.isalpha()]
As palavras que não são feitas só de letras. isalpha() aceita letras acentuadas: "pão".isalpha() é True.

Versão 3 · Contar com um dicionário e ordenar

Agora, a contagem. A ideia é a de uma folha com duas colunas, palavra e quantidade: para cada palavra do texto, a Ana procura a linha dela na folha e soma 1; se ainda não tem linha, cria uma com 1. Um dicionário é exatamente essa folha.

PONTUACAO = '.,;:!?"—'

with open("cronica.txt", encoding="utf-8") as arquivo:
    texto = arquivo.read()

texto = texto.lower()
for sinal in PONTUACAO:
    texto = texto.replace(sinal, " ")
palavras = texto.split()

contagem = {}
for palavra in palavras:
    contagem[palavra] = contagem.get(palavra, 0) + 1

print(f"Palavras: {len(palavras)}, diferentes: {len(contagem)}")
mais_usadas = sorted(contagem.items(), key=lambda par: par[1], reverse=True)
for palavra, vezes in mais_usadas[:10]:
    print(f"{palavra:<10} {vezes:>3}")
contagem = {}
A folha começa vazia: um dicionário sem nenhuma chave.
contagem.get(palavra, 0)
O número que já está anotado para a palavra, ou 0 se ela ainda não apareceu (aula Dicionários). É o que evita o KeyError (veja Quando dá errado).
contagem[palavra] = … + 1
Anota o número novo, criando a chave na primeira vez.
len(contagem)
Quantas chaves o dicionário tem, ou seja, quantas palavras diferentes.
contagem.items()
Os pares (palavra, vezes), como tuplas.
key=lambda par: par[1]
Ordena os pares pelo item 1 de cada um, o número de vezes (aula lambda).
reverse=True
Do maior para o menor.
mais_usadas[:10]
Só os 10 primeiros pares.
{palavra:<10} {vezes:>3}
A palavra à esquerda em 10 posições e o número à direita em 3: as colunas ficam retas.

Das 148 palavras, 77 são diferentes. A campeã é o, com 19, seguida de pão, com 9. Quando duas palavras empatam (e, de e café, com 5), o sorted as deixa na ordem em que apareceram pela primeira vez no dicionário, que é a ordem do texto.

Repare que pães conta separado de pão: para o programa, são textos diferentes. Juntar plural e singular é bem mais difícil, e fica fora deste projeto.

Versão 4 · Counter, palavras comuns e barras

A versão 3 funciona, mas o pódio é das palavras pequenas: o, do, e, de. Elas aparecem em qualquer texto e não dizem nada sobre ele. A versão final ignora essas palavras, troca a contagem manual pelo Counter, que já faz isso pronto, e desenha uma barra para cada palavra.

from collections import Counter

PONTUACAO = '.,;:!?"—'
IGNORAR = {
    "a", "o", "as", "os", "e", "é", "de", "do", "da", "no", "na",
    "à", "às", "um", "uma", "que", "ele", "sobre", "antes",
}


def ler_palavras(nome_arquivo):
    with open(nome_arquivo, encoding="utf-8") as arquivo:
        texto = arquivo.read().lower()
    for sinal in PONTUACAO:
        texto = texto.replace(sinal, " ")
    return texto.split()


palavras = ler_palavras("cronica.txt")
importantes = [p for p in palavras if p not in IGNORAR]
contagem = Counter(importantes)

print(f"Palavras: {len(palavras)}, sem as comuns: {len(importantes)}")
print("As 10 mais usadas:")
for palavra, vezes in contagem.most_common(10):
    print(f"{palavra:<10} {vezes:>3} {'#' * vezes}")
from collections import Counter
Traz o Counter ("contador") do módulo collections, que vem com o Python (aula O Módulo collections).
IGNORAR = {…}
Um conjunto com as palavras comuns (aula Conjuntos). Perguntar p not in IGNORAR num conjunto é rápido, mesmo com milhares de palavras. A lista foi escolhida olhando a saída da versão 3; para outro texto, você ajustaria.
def ler_palavras(nome_arquivo): … return texto.split()
A leitura e a limpeza das versões 1 e 2, agora numa função que devolve a lista pronta.
[p for p in palavras if p not in IGNORAR]
Uma lista nova, só com as palavras que interessam (aula List Comprehension).
Counter(importantes)
Conta tudo de uma vez: é um dicionário palavra → vezes, igual ao da versão 3.
contagem.most_common(10)
"As mais comuns": os 10 pares com mais vezes, já em ordem. Faz o trabalho do sorted com lambda e da fatia [:10].
'#' * vezes
Repete o # tantas vezes quanto a palavra apareceu: a barra (aula Juntar e Repetir Textos). Dentro da f-string, o '#' usa aspas simples porque a f-string usa aspas duplas.

Formas diferentes de limpar e de contar

Limpar a pontuação

Três jeitos que dão as mesmas 148 palavras com esta crônica:

import re

PONTUACAO = '.,;:!?"—'

with open("cronica.txt", encoding="utf-8") as arquivo:
    texto = arquivo.read().lower()

limpo1 = texto
for sinal in PONTUACAO:
    limpo1 = limpo1.replace(sinal, " ")

tabela = str.maketrans(PONTUACAO, " " * len(PONTUACAO))
limpo2 = texto.translate(tabela)

palavras3 = re.findall(r"\w+", texto)

print(len(limpo1.split()), len(limpo2.split()), len(palavras3))
print(limpo1.split() == limpo2.split() == palavras3)

Resumo

  • Leia o arquivo com with open(…, encoding="utf-8") e read(); separe as palavras com split(), sem argumento.
  • Antes de contar, limpe: lower() para as maiúsculas, replace (por espaço) para a pontuação. Confira o resultado: palavra com sinal, ou vazia, é sinal de limpeza incompleta.
  • Um dicionário conta com contagem.get(p, 0) + 1; ordene os pares com sorted(…, key=lambda par: par[1], reverse=True).
  • O Counter faz tudo isso numa linha, tem o most_common(n) e devolve 0 para o que não apareceu.
  • Palavras comuns (o, de, e) enchem o pódio: guarde-as num conjunto e filtre com uma list comprehension.
  • FileNotFoundError é nome ou pasta errada; UnicodeDecodeError é arquivo em outra codificação; KeyError é chave que ainda não existe.
